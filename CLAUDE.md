## What this project is

A static personal dev blog and portfolio site for YoungSuOh (오영수). It is deployed as a GitHub Pages site with no server-side runtime — all pages are pre-built HTML files.

## Build

```bash
npm run build
```

Runs `scripts/build.mjs` (Node.js ESM). No install step is needed (no runtime dependencies). There are no tests or lint commands.

## Architecture

The build pipeline has two sources of truth:

| File | Purpose |
|---|---|
| `site-config.json` | Site metadata, navigation, blog categories, projects, contacts |
| `data/posts.json` | All blog post metadata + content |

Running `npm run build` does two things:
1. Generates `posts/<Category>/<slug>.html` for every post in `data/posts.json`.
2. Regenerates `site-data.js` (`window.BLOG_DATA = {...}`) — the runtime data bundle loaded by `index.html`.

**Never edit `site-data.js` or `posts/**/*.html` directly** — they are overwritten on every build.

`index.html` is a static single-page frontend that reads `window.BLOG_DATA` (from `site-data.js`) to render navigation, blog listings, and project cards. Individual post pages are separate generated HTML files.

`projects/` pages are hand-authored and not generated by the build script. Likewise, `template.html` is a hand-authored reference template.

## Adding a new blog post

1. Add an entry to `data/posts.json` with the fields: `id`, `slug`, `title`, `category`, `summary`, `date`, `tags`, and either:
   - `bodyHtml` — inline HTML string, or
   - `bodyFile` — path relative to `data/` pointing to an HTML fragment (e.g. `"body/java/01-fundamentals-jvm.html"`).
2. Run `npm run build`.

The post is output at `posts/<CategoryDir>/<slug>.html`. Category directory names are derived by `categoryToDir()` in `scripts/build.mjs`: spaces become hyphens, ` / ` becomes `-`. For example, `"System Design"` → `System-Design`, `"DevOps / Infra"` → `DevOps-Infra`.

The valid category values (from `site-config.json`) are:
`Java`, `Backend`, `Dev`, `Troubleshooting`, `Database`, `DevOps / Infra`, `System Design`, `Algorithm`, `Computer Science`

## Adding or updating site-level content

- **Navigation / blog categories / contacts**: edit `site-config.json`, then rebuild.
- **Projects**: edit both `site-config.json` (for the index card) and create/update the corresponding page under `projects/`.
- **Styles**: edit `styles.css` (used by all pages via relative path).
