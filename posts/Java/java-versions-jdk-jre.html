Java 8, 11, 17 요약

Java 8 (2014, LTS 계열의 시작점으로 널리 사용)

핵심: 람다, Stream API, 인터페이스 default/static, java.time, Optional 등.

1) 람다

new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello, Java 8!");
    }
}).start();

new Thread(() -> System.out.println("Hello, Java 8!")).start();

2) Stream API

List<String> list = Arrays.asList("apple", "banana", "cherry");
list.stream()
    .filter(s -> s.startsWith("a"))
    .forEach(System.out::println);

3) 인터페이스 default & static

interface MyInterface {
    default void sayHello() {
        System.out.println("Hello from default method!");
    }
}

4) java.time

LocalDate today = LocalDate.now();
System.out.println(today);

5) 메서드 레퍼런스 — list.forEach(System.out::println);

6) Optional

Optional<String> optional = Optional.ofNullable(null);
System.out.println(optional.orElse("기본값"));

JDK와 JRE의 차이

JDK (Java Development Kit)

개발에 필요한 도구가 포함된 키트입니다. JRE + 컴파일러·디버거 등입니다.

구성 요소 설명
JRE 실행 환경
javac .java → 바이트코드 .class
java JVM에서 바이트코드 실행
jar 아카이브 패키징
jdb 디버거
javadoc 문서 생성

JRE (Java Runtime Environment)

프로그램 실행만 할 때 필요한 환경입니다. JDK의 일부이며, 개발 도구는 없고 JVM + 표준 라이브러리 중심입니다.

구성 요소 설명
JVM 바이트코드 실행
클래스 라이브러리 java.lang, java.util 등
클래스 로더 .class 로딩
GC 메모리 관리
