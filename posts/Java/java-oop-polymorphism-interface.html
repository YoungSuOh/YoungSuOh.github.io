오버로딩 vs 오버라이딩

오버로딩 (Method Overloading)

같은 클래스에서 이름은 같고 매개변수 목록만 다르게 정의합니다. 반환 타입만 다른 것으로는 오버로딩이 성립하지 않습니다.

class MathUtil {
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
    int add(int a, int b, int c) { return a + b + c; }
}

오버라이딩 (Method Overriding)

부모 메서드를 자식에서 같은 시그니처로 재정의합니다. 접근 제어자는 부모보다 좁아질 수 없습니다.

class Animal {
    void sound() { System.out.println("Some sound..."); }
}
class Dog extends Animal {
    @Override
    void sound() { System.out.println("Bark! Bark!"); }
}

다형성

같은 인터페이스(또는 상위 타입)로 여러 구현을 다루는 성질입니다. 오버로딩·오버라이딩과 연결됩니다.

  • 코드 재사용·유지보수, 인터페이스 기반 설계에 유리합니다.
  • 확장 시 기존 코드 수정을 줄이는 방향(OCP)과 맞닿아 있습니다.

상속과 조합

상속(Is-A)은 부모의 필드·메서드를 물려받고, 조합(Has-A)은 다른 객체를 필드로 들고 역할을 위임합니다.

상속 조합
관계 Is-A Has-A
방식 extends 필드로 객체 포함 
class Dog extends Animal {
    void bark() { System.out.println("Bark!"); }
}
class Car {
    private Engine engine;
    Car() { this.engine = new Engine(); }
    void startCar() { engine.start(); }
}

조합은 포함 객체를 교체하기 쉬워 유연성이 좋은 경우가 많습니다.

상속의 단점

  • 부모 변경이 자식 전파(강한 결합)
  • 쓰지 않는 메서드까지 물려받을 수 있음
  • 클래스 다중 상속 불가(다이아몬드 문제)
  • 깊은 계층은 복잡도 증가

instanceof

객체가 특정 클래스/인터페이스 타입인지 검사합니다. null에는 항상 false입니다.

Animal myDog = new Dog();
System.out.println(myDog instanceof Animal); // true
System.out.println(myDog instanceof Dog);    // true

구체 타입으로 분기가 늘어나면 추상화가 깨지고 OCP/SRP에 불리할 수 있어, 가능하면 다형성(공통 메서드 호출)으로 처리합니다.

Interface vs Abstract Class

항목 인터페이스 추상 클래스
목적 규약(무엇을 할지) 공통 구현 + 일부 강제
다중 상속/구현 여러 개 구현 가능 단일 상속
필드 주로 상수 성격 인스턴스 상태 가능
생성자 없음 있음 
class Dog implements Animal, Pet {
    public void makeSound() { System.out.println("Bark!"); }
    public void play() { System.out.println("Playing fetch!"); }
}
abstract class Vehicle {
    int speed;
    Vehicle(int speed) { this.speed = speed; }
    abstract void move();
    void stop() { System.out.println("Vehicle stopped."); }
}

final

  • final 변수: 한 번만 대입
  • final 메서드: 오버라이드 금지
  • final 클래스: 상속 금지 (String 등)

참조형이 final이어도 객체 내부 필드 변경은 막지 않습니다. 참조 자체의 재할당만 금지입니다.

final Car car = new Car("BMW");
car.model = "Audi"; // 가능
// car = new Car("Tesla"); // 불가
