Bit Masking

정수의 비트를 이용해 여러 상태를 한 번에 표현하는 기법

Bit Masking은 집합/상태 정보를 비트 단위로 저장해 메모리와 연산을 줄이는 방법이다.

핵심 연산

  • 추가: mask | (1 << k)
  • 삭제: mask & ~(1 << k)
  • 토글: mask ^ (1 << k)
  • 포함 확인: (mask & (1 << k)) != 0

Java 예제

int mask = 0;
mask |= (1 << 2);        // 2번 원소 추가
mask |= (1 << 4);        // 4번 원소 추가
boolean has2 = (mask & (1 << 2)) != 0;
mask &= ~(1 << 2);       // 2번 원소 제거

자주 쓰는 곳

  • 부분집합 순회 (for (sub = mask; sub > 0; sub = (sub - 1) & mask))
  • 방문 상태 압축 DP (TSP, 외판원 등)
  • 알파벳 출현 체크(26비트)
