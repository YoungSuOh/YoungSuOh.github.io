Binary Search

정렬된 리스트에서 탐색 범위를 절반씩 좁혀가는 탐색 방법

Binary SearchAlgorithmSearch

이분 탐색은 정렬되어 있는 리스트에서 탐색 범위를 전반씩 좁혀가며 데이터를 탐색하는 탐색 방법이다.

조건 2가지

  1. 배열이 정렬되어 있어야 한다.
  2. 무한 루프에 빠지지 않게 mid값을 정해야 한다.

구현 방법

  • 반복문을 이용한 방법
int BSearch(int arr[], int target) {
    int low = 0;
    int high = arr.length - 1;
    int mid;

    while(low <= high) {
        mid = (low + high) / 2;

        if (arr[mid] == target)
            return mid;
        else if (arr[mid] > target)
            high = mid - 1;
        else
            low = mid + 1;
    }
    return -1;
}
  • 재귀 함수를 이용한 방법
int BSearch(int arr[], int target, int low, int high) {
    if (low > high)
        return -1;

    int mid = (low + high) / 2;
    if (arr[mid] == target)
        return mid;
    else if (arr[mid] > target)
        return BSearch(arr, target, low, mid-1);
    else
        return BSearch(arr, target, mid+1, high);
}
