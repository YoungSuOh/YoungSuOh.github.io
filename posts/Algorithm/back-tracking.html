Back-Tracking

가능성이 없는 경로를 조기에 중단하며 탐색하는 기법

Algorithm

Back-Tracking은 DFS 기반 탐색에서 조건 위반 경로를 즉시 잘라내 시간 낭비를 줄이는 방식이다.

구조

  1. 선택(choose)
  2. 유효성 검사(pruning)
  3. 재귀 탐색
  4. 복구(un-choose)

Java 예제 (순열)

void perm(int[] arr, boolean[] used, List<Integer> path) {
    if (path.size() == arr.length) {
        System.out.println(path);
        return;
    }
    for (int i = 0; i < arr.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(arr[i]);
        perm(arr, used, path);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}

대표 문제

  • N-Queen
  • 부분집합/순열/조합 생성
  • 스도쿠, 미로 탐색의 제약 만족형 문제
