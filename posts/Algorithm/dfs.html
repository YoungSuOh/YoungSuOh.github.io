DFS (Depth-First Search)

한 경로를 끝까지 탐색한 뒤, 막히면 되돌아와 다른 경로를 탐색하는 방식

DFSGraphTraversal

DFS는 깊이 우선 탐색으로, 한 노드에서 시작해 가능한 한 깊게 들어간 뒤 더 이상 갈 곳이 없으면 백트래킹한다.

핵심 특징

  • 스택(Stack) 구조를 사용한다. (재귀 호출도 내부적으로 스택 사용)
  • 경로 탐색, 조합/순열, 백트래킹 문제와 궁합이 좋다.
  • 방문 여부 체크를 하지 않으면 사이클 그래프에서 무한 루프가 발생할 수 있다.

시간 복잡도

  • 인접 리스트 기준: O(V + E)
  • V: 정점 수, E: 간선 수

재귀 DFS (Java)

static void dfs(int node, List<List<Integer>> graph, boolean[] visited) {
    visited[node] = true;
    System.out.print(node + " ");

    for (int next : graph.get(node)) {
        if (!visited[next]) {
            dfs(next, graph, visited);
        }
    }
}

언제 많이 쓰나?

  • 연결 요소(Connected Component) 개수 세기
  • 사이클 탐지
  • 미로/격자에서 경로 존재 여부 확인
  • 트리 순회(전위/후위 등)
