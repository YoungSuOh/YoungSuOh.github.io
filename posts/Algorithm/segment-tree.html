Segment Tree

구간 합/최대/최소 질의와 점 업데이트를 빠르게 수행하기 위한 자료구조

Segment Tree Range Query Data Structure

: 주어진 데이터의 구간 합과 데이터 업데이트를 빠르게 수행하기 위한 자료구조. 이때 구간 합이라는 것은 합 배열을 뜻한다.

합 배열

  • 다음은 합 배열을 구하는 과정이다.
  • 합 배열의 현재 인덱스 값은 그전 인덱스까지의 누적합이다.
  • 2~5 인덱스의 구간 합은 합배열의 5에서 1을 빼서 구할 수 있다.

왜 세그먼트 트리를 사용해야 될까?

  • 데이터 업데이트 문제가 발생: 합 배열의 데이터 업데이트가 굉장히 느리다
  • 따라서 업데이트가 훨씬 빠른 Segment Tree를 사용한다.

세그먼트 트리의 종류

  • 구간 합, 구간 곱, 구간의 최대/최소

세그먼트 트리 구현하기

  1. 트리 초기화 하기
    1. leaf 노드 개수가 데이터 개수 N 이상이 되도록 트리 배열을 만든다.
    2. Sample data: {5, 8, 4, 3, 7, 2, 1, 6}
      1. 트리 크기: 2^k >= N을 만족하는 최소 k를 구한 뒤, 배열 크기를 2^(k+1)로 둔다.
      2. N=8이면 k=3, 배열 크기=16
    3. leaf 시작 인덱스는 2^k가 된다. (예: 8)
  1. 세그먼트 트리 조건에 맞게 트리 구성
    1. 구간 합
    2. 최대
    3. 최소
  1. 주어진 쿼리 인덱스를 세그먼트 트리 인덱스로 변경
    1. 세그먼트 트리 index = 주어진 질의 index + 2^k - 1
    2. 예: 쿼리 1~3이면 8~11
  2. 쿼리값 구하는 과정
    1. start_index % 2 == 1이면 해당 노드 선택
    2. end_index % 2 == 0이면 해당 노드 선택
    3. start_index = (start_index + 1) / 2
    4. end_index = (end_index - 1) / 2
    5. 선택된 노드들은 질의 범위에 영향을 주는 독립 노드다.

예제

  • 쿼리 2~6의 구간합 구하기

데이터 업데이트

  • 부모로 올라가며 갱신한다는 점은 같지만, 트리 종류별 갱신 방식은 다르다.
  • 구간 합: 변경량(diff)만큼 부모로 올라가며 더함
  • 최대: 형제 노드와 비교해 큰 값으로 부모 갱신
  • 최소: 형제 노드와 비교해 작은 값으로 부모 갱신

예제 코드 (Java)

import java.util.Arrays;

public class SegmentTreeExample {
    static class SegmentTree {
        private final int n;
        private final long[] tree;

        public SegmentTree(int[] arr) {
            this.n = arr.length;
            this.tree = new long[n * 4];
            build(arr, 1, 0, n - 1);
        }

        private void build(int[] arr, int node, int left, int right) {
            if (left == right) {
                tree[node] = arr[left];
                return;
            }
            int mid = (left + right) / 2;
            build(arr, node * 2, left, mid);
            build(arr, node * 2 + 1, mid + 1, right);
            tree[node] = tree[node * 2] + tree[node * 2 + 1];
        }

        // 구간 합 쿼리 [ql, qr]
        public long query(int ql, int qr) {
            return query(1, 0, n - 1, ql, qr);
        }

        private long query(int node, int left, int right, int ql, int qr) {
            if (qr < left || right < ql) return 0; // 겹치지 않음
            if (ql <= left && right <= qr) return tree[node]; // 완전 포함
            int mid = (left + right) / 2;
            return query(node * 2, left, mid, ql, qr)
                    + query(node * 2 + 1, mid + 1, right, ql, qr);
        }

        // 점 업데이트: index 값을 newValue로 변경
        public void update(int index, int newValue) {
            update(1, 0, n - 1, index, newValue);
        }

        private void update(int node, int left, int right, int index, int newValue) {
            if (index < left || right < index) return;
            if (left == right) {
                tree[node] = newValue;
                return;
            }
            int mid = (left + right) / 2;
            update(node * 2, left, mid, index, newValue);
            update(node * 2 + 1, mid + 1, right, index, newValue);
            tree[node] = tree[node * 2] + tree[node * 2 + 1];
        }
    }

    public static void main(String[] args) {
        int[] arr = {5, 8, 4, 3, 7, 2, 1, 6};
        SegmentTree seg = new SegmentTree(arr);

        System.out.println("초기 배열: " + Arrays.toString(arr));
        System.out.println("구간합 [1, 5] = " + seg.query(1, 5)); // 8+4+3+7+2 = 24

        // index 4(값 7) -> 10으로 업데이트
        seg.update(4, 10);
        arr[4] = 10;

        System.out.println("업데이트 후 배열: " + Arrays.toString(arr));
        System.out.println("구간합 [1, 5] = " + seg.query(1, 5)); // 27
    }
}
