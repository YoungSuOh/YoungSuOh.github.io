Minimal Spanning Tree(최소 신장 트리)

신장 트리의 개념과 MST를 구하는 Kruskal/Prim 알고리즘 정리

MSTKruskalPrim

사전 지식

Disjoint Set & Union Find

  • 신장 트리: 주어진 방향성이 없는 그래프의 부분 그래프들 중에서 모든 정점을 포함하는 트리를 의미
  • 부분 그래프: 주어진 그래프에서 일부 정점과 간선 만을 택해서 구성한 새로운 그래프를 의미
  • 오른쪽 그래프들은 전부 왼쪽 그래프의 신장 트리이다.
  • 오른쪽 그래프들이 전부 왼쪽 그래프의 신장 트리가 아니다
  • 첫번째는 가운데 정점이 연결되지 않았다. (연결 그래프여야 하는 트리의 조건 위배)
  • 두번째와 세번째 그래프는 사이클이 존재 → 신장트리가 아님
  • 네번째는 원래 없던 간선이 등장 → 부분 그래프가 아님

최소 신장 트리: 신장 트리 중에서 간선의 합이 최소인 트리를 의미

최소 신장 트리를 구하는 방법

크루스칼 알고리즘

가장 비용이 낮은 간선부터 시작해 간선을 크기 순으로 살펴보며 서로 떨어져 있던 정점들을 합쳐나가서 총 V-1개의 간선을 택하는 알고리즘이다.

  1. 간선을 크기를 오름차순으로 정렬하고 제일 낮은 비용의 간선을 선택
  2. 현재 선택한 간선이 정점 u, v를 연결하는 간선이라고 할 때, 만약 u, v가 같은 그룹이라면 넘어가고, 다른 그룹이라면 같은 그룹으로 만들고 현재 선택한 간선을 최소 신장 트리에 추가
  3. 최소 신장 트리에 V-1개의 간선을 추가시켰다면 종료
  • 맨 처음에는 모든 정점이 서로 다른 그룹에 속해 있는 상태로 시작
  • 비용이 가장 낮은 간선부터 선택한다.
  • 같은 그룹인 경우는 간선을 추가하지 않고 넘어간다.
  • 정점이 5개이면 간선 4개(V-1)를 고르면 MST 완성

같은 그룹인지 판단할 때 Flood Fill도 가능하지만 비효율적이다. Union-Find를 사용하면 거의 상수 시간으로 판별 가능해서 Kruskal을 O(E log E)에 해결할 수 있다.

Prim 알고리즘

한 정점에서 시작해 확장해 나가는 알고리즘.

  1. 임의의 정점을 선택해 최소 신장 트리에 추가
  2. MST에 포함된 정점과 포함되지 않은 정점을 연결하는 간선 중 비용이 가장 작은 것을 추가
  3. 간선이 V-1개가 될 때까지 반복
  • 다음은 프림 알고리즘의 수행 과정이다
  • 기본 구현은 O(VE)로 비효율적일 수 있다.
  • 따라서 우선순위 큐를 사용하면 효율적으로 개선할 수 있다.

C++ tuple

  • C++에서 tuple은 다양한 유형의 데이터 그룹을 단일 객체로 묶을 수 있는 자료구조이다.
  • 여러 개의 서로 다른 유형의 값을 하나의 단위로 다뤄야 할 때 유용하다.
  • tuple은 std::pair와 비슷하지만, 두 개 이상의 값을 저장할 수 있다.

사용법

#include <tuple>
#include <iostream>

int main() {
    std::tuple<int, double, std::string> myTuple(1, 3.14, "hello");
    // 다른 방법: auto를 사용하여 초기화
    auto myTuple2 = std::make_tuple(2, 2.71, "world");

    // 출력
    std::cout << std::get<0>(myTuple) << " ";
    std::cout << std::get<1>(myTuple) << " ";
    std::cout << std::get<2>(myTuple) << std::endl;

    return 0;
}

result
1 3.14 hello

tuple 엘리먼트 접근

int a = std::get<0>(t1); // 1
double b = std::get<1>(t2); // 3.5
std::string c = std::get<2>(t1); // Hello

std::tie를 사용한 값 추출

int x;
double y;
std::string z;
std::tie(x, y, z) = t1;

비교 연산(사전 순서)

if (t1 < t2) {
    std::cout << "t1 is less than t2" << std::endl;
}

tuple의 사용 시기

  1. 복합 데이터 반환 
    std::tuple<int, double, std::string> getData() {
    return std::make_tuple(1, 2.5, "Hello");
}
  2. 간단한 데이터 구조 
    std::tuple<int, int> coordinates = std::make_tuple(10, 20);
  3. 임시로 여러 데이터를 묶어서 처리 
    std::vector<std::tuple<int, int, int>> edges;
edges.push_back(std::make_tuple(1, 2, 3));
edges.push_back(std::make_tuple(4, 5, 6));
