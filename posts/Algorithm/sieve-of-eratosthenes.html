에라토스테네스의 체

N 이하 소수를 빠르게 구하는 대표적인 전처리 알고리즘

Algorithm

에라토스테네스의 체는 소수가 아닌 수를 배수 단위로 지워가며 소수를 찾는 방법이다.

원리

  • 2부터 시작해 아직 지워지지 않은 수를 소수로 확정
  • 해당 수의 배수를 모두 제거
  • 이를 i * i <= N까지 반복

복잡도

  • 시간: 대략 O(N log log N)
  • 공간: O(N)

Java 예제

int n = 100;
boolean[] isPrime = new boolean[n + 1];
Arrays.fill(isPrime, true);
isPrime[0] = isPrime[1] = false;

for (int i = 2; i * i <= n; i++) {
    if (!isPrime[i]) continue;
    for (int j = i * i; j <= n; j += i) {
        isPrime[j] = false;
    }
}
