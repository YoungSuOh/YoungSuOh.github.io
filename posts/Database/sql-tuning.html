SQL 튜닝(SQL Tuning)

SQL 튜닝은 느린 쿼리의 원인을 실행 계획과 통계로 분석해, 더 적은 비용으로 동일 결과를 얻도록 개선하는 작업이다.

튜닝 루프

  1. 느린 쿼리 수집(로그/APM)
  2. 실행 계획 확인(EXPLAIN/ANALYZE)
  3. 인덱스/쿼리 리라이트
  4. 재측정 후 회귀 테스트

자주 보는 안티패턴

  • SELECT * 남발
  • 인덱스 컬럼에 함수 적용(WHERE DATE(created_at)=...)
  • 불필요한 정렬/서브쿼리 중첩
  • N+1 쿼리

예제 리라이트

-- before
SELECT * FROM orders
WHERE DATE(created_at) = '2024-03-01';

-- after
SELECT id, user_id, total_amount
FROM orders
WHERE created_at >= '2024-03-01 00:00:00'
  AND created_at <  '2024-03-02 00:00:00';
