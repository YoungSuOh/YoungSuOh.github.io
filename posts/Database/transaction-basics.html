트랜잭션(Transaction)

트랜잭션은 여러 쿼리를 하나의 논리 작업으로 묶어, 전부 성공 또는 전부 실패를 보장하는 단위다.

ACID

  • Atomicity: 전부 성공/실패
  • Consistency: 제약 조건을 깨지 않는 일관된 상태 유지
  • Isolation: 동시에 실행되어도 서로 간섭 최소화
  • Durability: 커밋된 결과는 장애 후에도 유지

격리 수준과 대표 이슈

  • Read Uncommitted: Dirty Read 가능
  • Read Committed: Non-repeatable Read 가능
  • Repeatable Read: Phantom 가능(엔진마다 차이)
  • Serializable: 가장 안전하지만 성능 부담 큼

예제

START TRANSACTION;
UPDATE wallets SET balance = balance - 1000 WHERE user_id = 1;
UPDATE wallets SET balance = balance + 1000 WHERE user_id = 2;
COMMIT;

실무 체크리스트

  • 트랜잭션은 가능한 짧게
  • 외부 API 호출은 트랜잭션 밖으로 분리
  • 락 경합이 잦으면 격리 수준/쿼리 순서 재검토
