샤딩(Sharding)

샤딩은 데이터를 여러 물리 DB에 분산 저장해 단일 DB의 용량/성능 한계를 넘는 방법이다.

대표 방식

  • Range Sharding: 값 범위 기준 분할
  • Hash Sharding: 해시 기반 균등 분배
  • Directory Sharding: 별도 라우팅 테이블 사용

샤드 키 선택 기준

  • 쿼리 조건에 자주 포함되는 컬럼
  • 분포가 고르게 퍼지는 컬럼
  • 재샤딩 가능성까지 고려

트레이드오프

  • 장점: 쓰기 처리량/저장소 확장
  • 단점: 조인/집계 복잡화, 운영 난이도 상승
