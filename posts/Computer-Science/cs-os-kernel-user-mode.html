[OS] Kernel & User Mode

커널 모드와 유저 모드의 권한 차이, 시스템 콜·인터럽트·컨텍스트 스위치를 통한 모드 전환 메커니즘을 정리합니다.

Computer ScienceOS

두 가지 실행 모드

현대 OS에서 프로세스가 CPU를 사용할 수 있는 권한 수준을 나눈 두 가지 모드.

커널 모드 (Kernel Mode)
최고 권한. 하드웨어 자원 직접 접근/제어. 모든 명령어 실행 허용
유저 모드 (User Mode)
제한된 권한. 하드웨어 직접 접근 불가, 시스템 콜로 커널에 요청

커널 모드 특징

권한
무제한 — 모든 명령어와 메모리 주소 접근 가능
안정성
커널 코드 오류 = 시스템 크래시
실행 대상
파일 시스템, 메모리 관리, 네트워크 스택, 장치 드라이버

유저 모드 특징

권한
제한됨 — 하드웨어/특정 메모리 영역 접근 불가
안전성
한 유저 프로세스 오류가 다른 프로세스/시스템에 영향 없음
실행 대상
웹 브라우저, 사용자 애플리케이션

모드 전환 메커니즘

1. System Call

1유저 모드 프로세스가 시스템 콜 호출
2CPU가 커널 모드로 전환
3요청 작업 수행 후 유저 모드 복귀

2. 하드웨어 인터럽트

I/O 장치 요청 등으로 유저 모드 실행 중 커널 모드로 전환.

3. 컨텍스트 스위치

스케줄러에 의해 실행 중인 프로세스가 변경될 때. 현재 프로세스 상태 저장 + 다른 프로세스 상태 복원.
