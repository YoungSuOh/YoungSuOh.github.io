[Data Structure] 자료구조 한눈에 보기

Array·List·ArrayList·Stack·Queue·Deque·Tree·Hash Table 등 핵심 자료구조의 특징과 시간 복잡도를 한눈에 정리합니다.

Computer ScienceDataStructure

Array (배열)

저장
정적 크기. 연속 메모리
접근
인덱스 O(1)
삽입·삭제
O(N)
크기 초과
재할당 후 복사

List (연결 리스트)

저장
노드 연결
크기
제한 없음 (heap 한도)
접근
O(N) (참조 따라가기)
삽입·삭제
O(1)

ArrayList (동적 배열)

  • 가득차면 크기 2배로 할당하고 복사
  • 재할당 O(N)이지만 자주 일어나지 않으므로 접근 O(1)

Stack

📚
LIFO — 나중에 들어온 게 먼저 나감. top에서만 삽입·삭제. 함수 호출 시 지역변수·매개변수 저장

Queue & Deque

Queue
FIFO. rear에서 삽입(Enqueue), front에서 삭제(Dequeue)
Deque
양쪽(front·rear) 모두에서 삽입·삭제 가능. Stack + Queue 성질

Priority Queue

FIFO 아닌 우선순위 기반. 구현:

배열
간단하지만 삽입·삭제 O(N)
Linked List
삽입·삭제 O(1), 위치 찾기 O(N)
힙 ⭐
대부분 힙으로 구현. index 0 안 씀 (부모-자식 2배 관계)

Tree

  • 사이클 없는 무방향 그래프
  • 완전 이진트리 기준 높이 logN
  • 순회: 전위·중위·후위

BST

왼쪽 ⟨ 부모 ⟨ 오른쪽. 이상적 O(logN), 편향 O(N)

Hash Table

구조
key-value 쌍
해시 함수
key → 정수값(index)
충돌 처리
선형 조사, 이차 조사, 이중 해싱, 체이닝

map vs hashMap

map
BST(최근엔 Red-Black Tree). 접근·삽입·삭제 O(log N)
hashMap
해시 함수로 O(1). C++ STL 지원 안 함 (충돌 안정성 문제)
