[Data Structure] Stack & Queue

LIFO 스택과 FIFO 큐의 구조, push/pop/enQueue/deQueue 동작, 스택 포인터·front/rear 개념을 정리합니다.

Computer ScienceDataStructure

📚 Stack (스택)

Stack
입력과 출력이 한 곳(방향)으로 제한. LIFO (Last In First Out) — 나중에 들어온 게 먼저 나감

언제 사용?

  • 함수의 콜스택
  • 문자열 역순 출력
  • 연산자 후위표기법

push()
데이터 넣음
pop()
최상위 값 뺌
isEmpty()
비어있는지 확인
isFull()
꽉찼는지 확인

스택 포인터 (SP)

push와 pop 시 해당 위치를 기억해야 함. 다음 값이 들어갈 위치를 가리키며 초기값은 -1.

private int sp = -1;

public void push(Object o) {
    if (isFull()) return;
    stack[++sp] = o;
}

public Object pop() {
    if (isEmpty()) return null;
    return stack[sp--];
}

🚶 Queue (큐)

Queue
입력과 출력을 한 쪽 끝(front, rear)으로 제한. FIFO (First In First Out) — 먼저 들어온 게 먼저 나감

언제 사용?

  • 버퍼
  • 입력 처리 대기
  • BFS (너비 우선 탐색)

구조

front
큐의 가장 첫 원소. deQueue 위치
rear
큐의 끝 원소. enQueue 위치
💡
큐는 들어올 때 rear로, 나올 때는 front부터 빠지는 특성을 가짐

주요 연산

enQueue()

deQueue()
데이터 뺌 (front)
isEmpty()
비어있는지
isFull()
꽉찼는지
