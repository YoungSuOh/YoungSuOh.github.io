[Database] JOIN

INNER·LEFT/RIGHT OUTER·FULL OUTER·CROSS·SELF JOIN의 동작 차이와 실전 예제, PinterSemi 대댓글 실사례를 정리합니다.

Computer ScienceDB

두 개 이상의 테이블이나 데이터베이스를 연결하여 데이터를 검색하는 방법.

예제 테이블

EX_TABLEJOIN_TABLE
NO_EMPNAMEDEPTNO_EMPAGESALARY
1AliceHR12550000
2BobIT23060000
3CharlieFinance44070000

JOIN 종류

INNER JOIN — 교집합

SELECT A.NAME, B.AGE FROM EX_TABLE A
INNER JOIN JOIN_TABLE B ON A.NO_EMP = B.NO_EMP

기준 테이블과 join 테이블의 중복된 값만 표시. → Alice, Bob

LEFT OUTER JOIN

SELECT A.NAME, B.AGE FROM EX_TABLE A
LEFT OUTER JOIN JOIN_TABLE B ON A.NO_EMP = B.NO_EMP

왼쪽 테이블 기준. Charlie는 매칭 없으므로 AGE = NULL

RIGHT OUTER JOIN

오른쪽 테이블 기준. NO_EMP=4(AGE 40)는 NAME = NULL

FULL OUTER JOIN

양쪽 모두 기준. 일치하지 않는 값은 NULL로 채움

CROSS JOIN — 카타시안 곱

모든 경우의 수 (3 × 3 = 9개 행)

SELF JOIN

자기자신과 조인. 계층 구조(상사-부하), 값 비교에 사용

JOIN 종류 한눈에

INNER
양쪽 매칭만
LEFT OUTER
왼쪽 전부 + 매칭
RIGHT OUTER
오른쪽 전부 + 매칭
FULL OUTER
양쪽 전부
CROSS
카타시안 곱
SELF
자기 자신 조인
