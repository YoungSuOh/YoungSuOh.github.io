[Network] TLS/SSL HandShake

HTTPS의 SSL/TLS 핸드셰이크 5단계(Client Hello → Server Hello → 인증서 검증 → 키 교환 → Finished)를 정리합니다.

Computer ScienceNetwork
TLS/SSL Handshake
HTTPS에서 클라이언트와 서버 간 통신 전 SSL 인증서로 신뢰성을 판단하기 위해 연결하는 방식

핸드셰이크 5단계

1Client Hello
지원 암호화 방식(Cipher Suite), TLS 버전, 랜덤 값 전송
2Server Hello
서버가 암호화 방식 선택, 서버 랜덤 값 + SSL/TLS 인증서(공개키 포함) 전달
3인증서 검증
신뢰할 수 있는 CA에서 발급되었는지 확인. 유효하지 않으면 연결 종료
4키 교환
클라이언트가 세션 키 생성, 서버의 공개키로 암호화하여 전송
5Finished
공유 세션 키로 메시지 암호화. 핸드셰이크 종료 후 모든 데이터 암호화 전송
🔐
비대칭키로 세션키 안전하게 교환 → 이후 대칭키(세션키)로 빠른 데이터 통신
