[OS] Operating System

운영체제의 5가지 핵심 역할 — 프로세스·저장장치·네트워킹·사용자·디바이스 드라이버 관리를 한눈에 정리합니다.

Computer ScienceOS
운영체제(OS)란?
하드웨어와 컴퓨터 시스템의 자원들을 효율적으로 관리하고, 사용자가 컴퓨터를 편리하게 사용할 수 있게 하는 소프트웨어

운영체제의 5가지 역할

1프로세스 관리
프로세스·스레드, 스케줄링, 동기화, IPC 통신
2저장장치 관리
메모리, 가상 메모리, 파일 시스템
3네트워킹
TCP/IP, 기타 프로토콜
4사용자 관리
계정·접근권한 관리
5디바이스 드라이버
순차/임의 접근 장치, 네트워크 장치

각 역할 상세

1. 프로세스 관리

현재 CPU를 점유해야 할 프로세스를 결정하고, 실제로 CPU를 프로세스에 할당하며, 프로세스 간 공유 자원 접근과 통신을 관리한다.

2. 저장장치 관리

1차 저장장치
Main Memory — 프로세스 메모리 영역 할당/해제, 영역 간 침범 방지, 가상 메모리
2차 저장장치
HDD, NAND — 파일 형식 데이터 저장, FAT/NTFS/EXT2/JFS/XFS 등 파일 시스템

3. 네트워킹

TCP/IP 기반 인터넷에 연결하거나 응용 프로그램이 네트워크를 사용하려면 운영체제에서 네트워크 프로토콜을 지원해야 한다.

4. 사용자 관리

하나의 PC를 여러 사용자가 쓰는 환경을 지원해야 한다. 사용자별 프라이버시·보안을 위해 개인 파일에 다른 사용자가 접근할 수 없도록 한다.

5. 디바이스 드라이버

운영체제 안에 하드웨어를 추상화해주는 계층이 디바이스 드라이버다. 응용 프로그램이 하드웨어를 사용할 수 있게 만든다.

한 줄 요약: OS는 프로세스·저장장치·네트워킹·사용자·디바이스 드라이버 5가지를 관리한다.
