[Data Structure] Linked List

연결 리스트의 구조와 4가지 종류(Single·Doubly·Circular Single·Circular Doubly)를 비교하여 각각의 특징과 사용 예시를 정리합니다.

Computer ScienceDataStructure
Linked List
연속적인 메모리 위치에 저장되지 않는 선형 데이터 구조. 포인터로 연결. 각 노드는 데이터 + 다음 노드 참조

왜 사용?

📦
배열은 크기 고정, 새 요소 삽입에 비용이 많이 듬(공간 만들고 기존 요소 전부 이동)
장점
동적 크기, 삽입/삭제 용이
단점
임의 액세스 불가 (순차 액세스), 포인터 메모리 추가 필요

구현 (Node 구조)

struct Node {
    int data;
    struct Node *next;
};

4가지 종류

1. Single Linked List

  • 한 방향(→) 연결. 다음 노드만 가리킴
  • 중간 삽입/삭제 시 앞 노드 찾아야 해서 O(n) 필요
  • 단순, 메모리 절약 (뒤로 가는 포인터 없음)

📌 사용: Stack, Queue, 간단한 데이터 연결

2. Doubly Linked List

  • 양방향(↔) 연결. prev + next 포인터
  • 뒤로 이동 가능
  • 삽입/삭제 O(1) (중간 삽입 시 앞 노드 찾으면 빠름)
  • 메모리 사용량 증가

📌 사용: 웹 브라우저 히스토리, LRU 캐시

3. Circular Singly Linked List

  • 마지막 노드가 nullptr이 아니라 처음으로 돌아감
  • 항상 순환 — 무한 루프 가능, 종료 조건 필요

📌 사용: Round-robin 스케줄링, 멀티플레이어 턴 시스템, 음악 반복 재생

4. Circular Doubly Linked List

  • 양방향 + 순환
  • 메모리 가장 많이 사용
  • 빠른 접근 가능

📌 사용: 시계 시스템, 데이터 버퍼, 게임 UI 메뉴 순환
