[Data Structure] Heap

우선순위 큐를 위한 완전 이진 트리 구조의 힙. Max Heap·Min Heap의 특징, 부모-자식 인덱스 관계, 삽입(Up Heap)·삭제(Down Heap) 동작을 정리합니다.

Computer ScienceDataStructure
Heap
우선순위 큐를 위해 만들어진 자료구조. 완전 이진 트리의 일종. 중복된 값 허용 (BST는 중복 X)

2가지 종류

Max Heap
부모 ≥ 자식. 최댓값이 루트
Min Heap
부모 ≤ 자식. 최솟값이 루트

부모-자식 인덱스 관계

왼쪽 자식 index = (부모 index) × 2
오른쪽 자식 index = (부모 index) × 2 + 1
부모 index = (자식 index) / 2
💡
index 0은 안 씀 — 부모-자식 2배 관계를 유지하기 위해

힙의 삽입 (Up Heap)

1마지막 노드에 새 요소 추가
2부모와 비교 후 교환
부모보다 크면(Max Heap) 교환
void insert_max_heap(int x) {
    maxHeap[++heapSize] = x;  // 마지막 노드에 추가
    for (int i = heapSize; i > 1; i /= 2) {
        if (maxHeap[i/2] < maxHeap[i]) swap(i/2, i);
        else break;
    }
}

힙의 삭제 (Down Heap)

1루트 노드 삭제
최대 힙: 최댓값 = 루트
2마지막 노드를 루트로 이동
3힙 재구성
자식 중 큰 값과 교환
int delete_max_heap() {
    int item = maxHeap[1];          // 루트 저장
    maxHeap[1] = maxHeap[heapSize]; // 마지막을 루트로
    maxHeap[heapSize--] = 0;
    // ... heapify down
    return item;
}
