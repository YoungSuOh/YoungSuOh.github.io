[Architecture] CPU

CPU의 구성(ALU·CU·레지스터), 명령어 사이클(Fetch·Decode·Execute), 성능 결정 요소(클럭·코어·캐시·ISA)를 정리합니다.

Computer ScienceArchitecture
CPU
컴퓨터에서 가장 핵심적인 역할을 수행하는 '인간의 두뇌'. 연산장치, 제어장치, 레지스터 3가지로 구성

CPU 구성

연산장치 (ALU)
산술·논리 연산. 데이터를 레지스터에서 가져와 연산 결과를 레지스터로 저장
제어장치 (CU)
명령어를 해독하고 실행을 제어. ALU·주기억·I/O 장치에 제어 신호 전송
레지스터
CPU 내부 초고속 임시 저장. 범용 + 특수목적

특수목적 레지스터

레지스터역할
MAR읽거나 쓸 메모리 주소 저장
PC다음 실행할 명령어 메모리 주소
IR현재 실행 중인 명령어
MBR메모리에서 읽거나 저장할 데이터
AC연산 결과 (누산기)

명령어 세트 (Instruction Set)

연산
ADD, SUB, MUL
제어
JUMP, CALL, RETURN
데이터 전달
LOAD, STORE
입출력
IN, OUT

명령어 사이클 (Instruction Cycle)

Fetch 사이클

T0: MAR ← PC T1: MBR ← M[MAR], PC ← PC + 1 T2: IR ← MBR

Execute 사이클 — ADD addr

T0: MAR ← IR(Addr) T1: MBR ← M[MAR] T2: AC ← AC + MBR

클럭 속도
GHz. 1초당 실행 가능한 명령어 사이클
코어 개수
독립 실행 장치 개수
캐시 메모리
L1, L2, L3. 자주 쓰는 데이터 저장
아키텍처
CISC(x86), RISC(ARM)
