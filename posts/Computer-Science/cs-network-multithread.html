POSIX Threads

#include <pthread.h>

int pthread_create(
    pthread_t *thread,
    const pthread_attr_t *attr,
    void *(*start_routine)(void*),
    void *arg
);

int pthread_join(pthread_t thread, void **status);
pthread_create
스레드 생성. start_routine은 스레드의 main 함수
pthread_join
지정 스레드가 종료될 때까지 대기
💡
컴파일 시 -lpthread 옵션 필수. 쓰레드 안전 함수 사용 시 -D_REENTRANT 옵션 추가.

임계영역 (Critical Section)

임계영역
함수 내에 둘 이상의 쓰레드가 동시에 실행하면 문제를 일으키는 하나 이상의 문장으로 묶여있는 코드 블록

동시 접근 문제 예시

// thread1과 thread2가 동시에 실행
num += 1;  // 임계영역!
🚨
두 스레드가 num=99 동시 참조 → 각각 1 증가 → 모두 100 저장. 2 증가 기대했지만 1만 증가

해결: 동기화(Synchronization) — 한 스레드가 변수에 접근해 연산을 완료할 때까지 다른 스레드 접근 금지.
