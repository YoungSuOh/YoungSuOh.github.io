[OS] Process & Thread

프로세스와 스레드의 메모리 구조, PCB, 멀티 프로세스 vs 멀티 스레드의 트레이드오프를 정리합니다.

Computer ScienceOS

프로세스

Process
실행 중인 프로그램. OS로부터 주소공간·파일·메모리 등을 할당받음. 각 프로세스는 독립된 메모리 공간을 사용하며 프로세스 간 데이터 공유는 어려움

PCB (Process Control Block)

특정 프로세스의 중요한 정보를 저장하는 OS 자료구조. 프로세스 생성과 동시에 고유한 PCB 생성.

PID
프로세스 식별자
상태
new, ready, running, waiting, terminated
PC
다음 실행할 명령어 주소
레지스터
CPU 레지스터 값
스케줄링
우선순위, 큐 포인터
메모리
페이지/세그먼트 테이블

스레드

Thread
프로세스 내에서 실행되는 독립적인 작업 흐름. 같은 프로세스 내 스레드는 메모리(힙 영역)를 공유하여 통신이 간단하지만 동기화 문제가 발생할 수 있음

멀티 프로세스 vs 멀티 스레드

구분멀티 프로세스멀티 스레드
메모리 구조서로 분리된 메모리 공간프로세스 내 메모리 공유
생성/종료 비용큼작음
안정성한 프로세스 죽어도 영향 없음한 스레드 문제가 전체에 영향
통신IPC(파이프/소켓/공유메모리)메모리 공유로 빠름. 동기화 주의
사용 예독립 모듈 분리, MSA병렬 계산, 빠른 협업

선택 기준

멀티 프로세스 유리
독립 모듈 분리·안전성, 하나가 죽어도 다른 모듈에 영향 없음, OS 보호 활용
멀티 스레드 유리
공유 데이터 많음, 쓰레드 간 빠른 통신, 여러 코어 활용 (이미지 처리·ML)
