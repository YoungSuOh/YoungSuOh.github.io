OSI 7 계층
네트워크에서 통신이 일어나는 과정을 7단계로 나눈 것

7계층 모델

7Application
HTTP, FTP, SMTP — 사용자 응용 프로그램
6Presentation
데이터 표현·암호화·압축
5Session
세션 관리, 연결 설정/해제
4Transport
TCP/UDP — 신뢰성 있는 전송, 흐름·혼잡 제어
3Network
IP, 라우팅 — 경로 선택
2Data Link
Ethernet, MAC — 프레임 단위 전송
1Physical
전기 신호, 케이블 — 실제 데이터 전송 매체
