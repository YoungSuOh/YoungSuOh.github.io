Composite 패턴

한 줄 정의

부분(Leaf)과 전체(Composite)를 동일 인터페이스로 취급해 트리 구조를 단일 방식으로 다루는 패턴.

언제 쓰는가?

  • 파일/폴더, 조직도, 메뉴 트리, UI 컴포넌트 트리
  • 재귀 구조를 일관된 API로 처리하고 싶을 때

Java 예제

import java.util.*;

interface FileSystemNode {
    int getSize();
}

class FileLeaf implements FileSystemNode {
    private final int size;
    FileLeaf(int size) { this.size = size; }
    public int getSize() { return size; }
}

class FolderComposite implements FileSystemNode {
    private final List<FileSystemNode> children = new ArrayList<>();

    void add(FileSystemNode node) { children.add(node); }

    public int getSize() {
        int sum = 0;
        for (FileSystemNode child : children) sum += child.getSize();
        return sum;
    }
}

장점 / 단점

  • 장점: 클라이언트 코드 단순화(Leaf/Composite 구분 최소화)
  • 단점: 일부 Leaf에 불필요한 메서드가 생길 수 있음
