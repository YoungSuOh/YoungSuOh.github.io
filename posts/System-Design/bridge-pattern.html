2024-07-18 · System Design

Bridge 패턴

한 줄 정의

추상 계층과 구현 계층을 분리해 각각 독립적으로 확장할 수 있도록 만드는 패턴.

문제 상황

예를 들어 도형 종류(원/사각형)와 렌더링 방식(Vector/Raster)이 동시에 늘어나면 상속만으로는 클래스 수가 급증한다.

해결 전략

  • 도형(추상화)과 렌더러(구현)를 분리
  • 상속 대신 조합으로 연결

Java 예제

interface Renderer {
    void drawCircle(float x, float y, float radius);
}

class VectorRenderer implements Renderer {
    public void drawCircle(float x, float y, float radius) {
        System.out.println("Vector circle: " + radius);
    }
}

abstract class Shape {
    protected final Renderer renderer;
    protected Shape(Renderer renderer) { this.renderer = renderer; }
    abstract void draw();
}

class Circle extends Shape {
    private final float x, y, r;
    Circle(Renderer renderer, float x, float y, float r) {
        super(renderer); this.x = x; this.y = y; this.r = r;
    }
    void draw() { renderer.drawCircle(x, y, r); }
}

장점 / 단점

  • 장점: 확장 축이 늘어나도 클래스 폭증을 억제
  • 단점: 초기 설계 복잡도 증가
