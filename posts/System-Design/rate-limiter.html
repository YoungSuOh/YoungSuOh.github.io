RateLimiter (속도 제한기)

초당 요청 수(RPS)를 제한해 API 남용과 트래픽 폭주를 방어하는 RateLimiter — Token Bucket·Leaky Bucket 알고리즘 비교와 Spring Filter 적용 예시를 정리합니다.

System DesignRate LimitingSpringAPI

초당 요청 수(RPS)를 강제로 제한하는 메커니즘.

✅ 언제 쓰나?

  • API 남용 방지
  • 트래픽 폭주 방어
  • 공정성 보장 (user별 quota)

✅ 동작 방식

Client → [RateLimiter] → Server
  • 초당 100개 제한이면 101번째 요청 → 거절 or 대기

대표 알고리즘

1. Token Bucket

  • 일정 속도로 토큰 생성
  • 요청이 토큰 소비

→ burst 허용 가능

2. Leaky Bucket

  • 일정한 속도로 요청 처리

✅ Spring에서 예시

@Component
public class RateLimitFilter extends OncePerRequestFilter {
    protected void doFilterInternal(...) {
        if (!rateLimiter.allow(key)) {
            response.setStatus(429);
            return;
        }
        filterChain.doFilter(request, response);
    }
}
