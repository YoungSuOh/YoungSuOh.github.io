Proxy 패턴

Proxy 패턴 정리

System Design

한 줄 정의

실제 객체 접근 전/후에 제어 로직을 삽입하기 위해 대리 객체를 두는 패턴.

대표 종류

  • Virtual Proxy: 지연 로딩
  • Protection Proxy: 접근 권한 확인
  • Cache Proxy: 캐싱 처리

Java 예제

interface ReportService {
    String getReport(long id);
}

class RealReportService implements ReportService {
    public String getReport(long id) { return "report#" + id; }
}

class ReportServiceProxy implements ReportService {
    private final ReportService target = new RealReportService();
    private final Map<Long, String> cache = new HashMap<>();

    public String getReport(long id) {
        if (cache.containsKey(id)) return cache.get(id);
        String value = target.getReport(id);
        cache.put(id, value);
        return value;
    }
}

장점 / 단점

  • 장점: 공통 부가 기능(권한/캐시/로깅) 분리
  • 단점: 객체 수와 간접 호출이 늘어 구조 이해 비용 증가

실무 포인트

  • JPA Lazy Loading은 엔티티 대신 프록시 객체를 먼저 반환
  • Spring AOP도 프록시를 이용해 횡단 관심사를 적용한다.
