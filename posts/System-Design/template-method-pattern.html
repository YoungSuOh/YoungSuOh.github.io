Template Method 패턴 정리

System Design

한 줄 정의

알고리즘의 전체 흐름은 상위 클래스에 고정하고, 일부 단계만 하위 클래스에서 구현하도록 하는 패턴.

왜 쓰는가?

  • 처리 순서는 공통인데 단계별 구현만 달라질 때
  • 프로세스 흐름의 일관성을 강제하고 싶을 때

Java 예제

abstract class ImportJob {
    public final void run() {
        validate();
        transform();
        save();
        afterSave();
    }

    protected void validate() { System.out.println("common validate"); }
    protected abstract void transform();
    protected abstract void save();
    protected void afterSave() {}
}

class CsvImportJob extends ImportJob {
    protected void transform() { System.out.println("csv transform"); }
    protected void save() { System.out.println("csv save"); }
}

장점 / 단점

  • 장점: 공통 흐름 재사용, 순서 보장
  • 단점: 상속 구조 의존이 커질 수 있음
