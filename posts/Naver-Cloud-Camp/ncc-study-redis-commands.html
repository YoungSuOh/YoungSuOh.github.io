Redis 명령어 모음

Redis 명령어 모음 — Naver Cloud Camp 정리 노트.

프로젝트Naver Cloud Camp

1. 일반 관리 명령어

  • PING: Redis 서버의 응답 확인. (PONG 반환)
  • SELECT <db-index>: 데이터베이스 선택 (기본값: 0).
  • FLUSHDB: 현재 데이터베이스의 모든 키 삭제.
  • FLUSHALL: 모든 데이터베이스의 키 삭제.
  • INFO: Redis 서버의 정보와 상태 반환.
  • CONFIG GET <parameter>: 특정 설정 값 조회.
  • CONFIG SET <parameter> <value>: 설정 값 변경.
  • SHUTDOWN: Redis 서버 종료.

2. Key 관련 명령어

  • KEYS <pattern>: 특정 패턴과 일치하는 모든 키 조회.
  • EXISTS <key>: 특정 키가 존재하는지 확인.
  • DEL <key>: 특정 키 삭제.
  • EXPIRE <key> <seconds>: 키의 TTL(Time to Live) 설정.
  • TTL <key>: 키의 남은 TTL 조회.
  • RENAME <key> <newkey>: 키 이름 변경.
  • TYPE <key>: 키의 데이터 타입 반환.

3. String 관련 명령어

  • SET <key> <value>: 키에 문자열 값 설정.
  • GET <key>: 키의 값 조회.
  • GETSET <key> <value>: 기존 값을 반환하고 새 값 설정.
  • INCR <key>: 키의 값을 1 증가.
  • INCRBY <key> <value>: 키의 값을 지정한 수만큼 증가.
  • DECR <key>: 키의 값을 1 감소.
  • DECRBY <key> <value>: 키의 값을 지정한 수만큼 감소.
  • MGET <key1> <key2>: 여러 키의 값 조회.
  • MSET <key1> <value1> <key2> <value2>: 여러 키-값 설정.

4. Hash 관련 명령어

  • HSET <key> <field> <value>: 해시 필드 설정.
  • HGET <key> <field>: 해시 필드 값 조회.
  • HDEL <key> <field>: 해시 필드 삭제.
  • HEXISTS <key> <field>: 해시 필드 존재 확인.
  • HGETALL <key>: 모든 필드와 값을 반환.
  • HINCRBY <key> <field> <value>: 해시 필드 값 증가.
  • HLEN <key>: 해시 필드의 개수 반환.

5. List 관련 명령어

  • LPUSH <key> <value>: 리스트 왼쪽에 값 삽입.
  • RPUSH <key> <value>: 리스트 오른쪽에 값 삽입.
  • LPOP <key>: 리스트 왼쪽에서 값 제거 및 반환.
  • RPOP <key>: 리스트 오른쪽에서 값 제거 및 반환.
  • LRANGE <key> <start> <end>: 지정된 범위의 리스트 요소 반환.
  • LLEN <key>: 리스트 길이 반환.
  • LREM <key> <count> <value>: 리스트에서 값 삭제.

6. Set 관련 명령어

  • SADD <key> <value>: 셋에 값 추가.
  • SREM <key> <value>: 셋에서 값 제거.
  • SMEMBERS <key>: 셋의 모든 값 반환.
  • SISMEMBER <key> <value>: 값의 존재 여부 확인.
  • SCARD <key>: 셋의 요소 개수 반환.
  • SUNION <key1> <key2>: 두 셋의 합집합 반환.
  • SINTER <key1> <key2>: 두 셋의 교집합 반환.
  • SDIFF <key1> <key2>: 두 셋의 차집합 반환.

7. Sorted Set 관련 명령어

  • ZADD <key> <score> <value>: 정렬된 셋에 값 추가.
  • ZRANGE <key> <start> <stop>: 정렬된 셋의 범위 내 값 반환.
  • ZREM <key> <value>: 정렬된 셋에서 값 제거.
  • ZSCORE <key> <value>: 값의 점수 반환.
  • ZCARD <key>: 정렬된 셋의 요소 개수 반환.
  • ZRANK <key> <value>: 값의 순위 반환.

8. Pub/Sub 관련 명령어

  • PUBLISH <channel> <message>: 특정 채널에 메시지 발행.
  • SUBSCRIBE <channel>: 채널 구독.
  • PSUBSCRIBE <pattern>: 패턴과 일치하는 채널 구독.
  • UNSUBSCRIBE <channel>: 채널 구독 취소.
  • PUBSUB CHANNELS: 현재 활성화된 채널 조회.
  • PUBSUB NUMSUB: 특정 채널의 구독자 수 조회.

9. HyperLogLog 관련 명령어

  • PFADD <key> <value>: HyperLogLog에 값 추가.
  • PFCOUNT <key>: 고유 값의 근사 개수 반환.
  • PFMERGE <dest> <source1> <source2>: 두 HyperLogLog 병합.

10. 기타 고급 명령어

  • BITSET <key> <offset> <value>: 비트 값 설정.
  • BITCOUNT <key>: 비트 값의 1 개수 세기.
  • GEOADD <key> <longitude> <latitude> <member>: 지리적 위치 추가.
  • GEODIST <key> <member1> <member2>: 두 위치 간 거리 반환.
  • GEOHASH <key> <member>: 지리적 위치의 해시 값 반환.

Pub/Sub 관련 명령어

  1. publish
    1. 특정 채널에 메세지를 발행한다.
      1. 명령어 
        PUBLISH <channel> <message>
      2. 예시 
        PUBLISH news_channel "Breaking news: Redis is amazing!"
      3. 코드 예시 
        import redis.clients.jedis.Jedis;

public class RedisPublisher {
    public static void main(String[] args) {
        // Redis 연결
        Jedis jedis = new Jedis("localhost", 6379);

        // 메시지 발행
        String channel = "news_channel";
        String message = "Breaking news: Redis with Java!";
        
        jedis.publish(channel, message);

        System.out.println("Message published to channel: " + channel);

        jedis.close();
    }
}
  2. subscribe
    1. 특정 채널을 구독한다. 구독 중인 채널에서 메세지가 발행되면 실시간으로 수신한다.
      1. 명령어 
        SUBSCRIBE <channel>
      2. 예시 
        SUBSCRIBE news_channel
      3. 코드 예시 
        import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPubSub;

public class RedisSubscriber {
    public static void main(String[] args) {
        // Redis 연결
        Jedis jedis = new Jedis("localhost", 6379);

        // 채널 구독
        String channel = "news_channel";
        JedisPubSub subscriber = new JedisPubSub() {
            @Override
            public void onMessage(String channel, String message) {
                System.out.println("Received message: " + message + " from channel: " + channel);
            }
        };

        System.out.println("Subscribed to channel: " + channel);
        jedis.subscribe(subscriber, channel);

        jedis.close();
    }
}
  3. psubscribe
    1. 패턴 기반으로 채널을 구독한다
    2. 와인드 카드 (*)를 사용해 여러 채널을 일괄 구독할 수 있다.
      1. 명령어 
        PSUBSCRIBE <pattern>
      2. 예시 
        PSUBSCRIBE news_*
      3. 코드 예시 
        import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPubSub;

public class RedisPatternSubscriber {
    public static void main(String[] args) {
        // Redis 연결
        Jedis jedis = new Jedis("localhost", 6379);

        // 패턴 구독
        String pattern = "news_*";
        JedisPubSub patternSubscriber = new JedisPubSub() {
            @Override
            public void onPMessage(String pattern, String channel, String message) {
                System.out.println("Pattern matched: " + pattern);
                System.out.println("Received message: " + message + " from channel: " + channel);
            }
        };

        System.out.println("Subscribed to pattern: " + pattern);
        jedis.psubscribe(patternSubscriber, pattern);

        jedis.close();
    }
}
  4. unsubscribe
    1. 특정 채널의 구독을 취소
    2. 모든 채널에서 구독을 취소하려면 채널 이름을 생략
      1. 명령어 
        UNSUBSCRIBE <channel>
      2. 예시 
        UNSUBSCRIBE news_channel
      3. 코드 예시 
        import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPubSub;

public class RedisUnsubscribe {
    public static void main(String[] args) {
        Jedis jedis = new Jedis("localhost", 6379);

        // 구독자 정의
        JedisPubSub subscriber = new JedisPubSub() {
            @Override
            public void onMessage(String channel, String message) {
                System.out.println("Received message: " + message);
            }

            @Override
            public void onSubscribe(String channel, int subscribedChannels) {
                System.out.println("Subscribed to: " + channel);
            }

            @Override
            public void onUnsubscribe(String channel, int subscribedChannels) {
                System.out.println("Unsubscribed from: " + channel);
            }
        };

        // 채널 구독
        new Thread(() -> jedis.subscribe(subscriber, "news_channel")).start();

        // 잠시 대기 후 구독 취소
        try {
            Thread.sleep(5000);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        subscriber.unsubscribe();
        jedis.close();
    }
}
  5. pubsub channels
    1. 현재 활성화된 채널 목록을 반환한다.
      1. 명령어 
        PUBSUB CHANNELS [pattern]
      2. 예시 
        PUBSUB CHANNELS news_*
      3. 코드 예시 
        import redis.clients.jedis.Jedis;

public class RedisPubSubChannels {
    public static void main(String[] args) {
        Jedis jedis = new Jedis("localhost", 6379);

        // 현재 활성화된 채널 조회
        System.out.println("Active channels: " + jedis.pubsubChannels("*"));

        jedis.close();
    }
}
  6. pubsub numsub
    1. 특정 채널의 구독자 수를 반환
      1. 명령어 
        pubsub numsub <channel>
      2. 예시
        1. pubsub numsub news_channel
      3. 코드 예시 
        import redis.clients.jedis.Jedis;

public class RedisNumSub {
    public static void main(String[] args) {
        Jedis jedis = new Jedis("localhost", 6379);

        // 특정 채널 구독자 수 조회
        System.out.println("Subscribers for 'news_channel': " + jedis.pubsubNumSub("news_channel"));

        jedis.close();
    }
}
  7. pubsub numpat
    1. 특정 채널의 구독자 수를 반환
      1. 명령어 
        PUBSUB NUMPAT
      2. 예시 
        PUBSUB NUMPAT
      3. 코드 예시 
        import redis.clients.jedis.Jedis;

public class RedisNumPat {
    public static void main(String[] args) {
        Jedis jedis = new Jedis("localhost", 6379);

        // 패턴 구독자의 수 조회
        System.out.println("Number of pattern subscriptions: " + jedis.pubsubNumPat());

        jedis.close();
    }
}
