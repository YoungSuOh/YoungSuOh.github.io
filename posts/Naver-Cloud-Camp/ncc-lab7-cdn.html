Lab7 CDN 사용해보기

Lab7 CDN 사용해보기 — Naver Cloud Camp 정리 노트.

NCP LabNaver Cloud Camp

학습 목표

  1. CDN - 프라이빗 컨텐트에 대한 액세스 제한
    1. Referrer 설정을 통한 인가된 요청만 컨텐츠 딜리버리 설정
  1. CDN 설정 변경
    1. Services >contentsdelivery >CDN+
    2. 서비스이름 : lab-cdn 선택 후 설정 변경 선택
    3. Viewer 전송 설정에서
    4. ReferrerDomain : 사용
    5. 도메인 리스트 : 로드밸런서에서의 lab-alb 접속 정보 입력
    6. 레퍼러 없는 경우 허용 여부 : 허용 안함 선택
      1. Reffer 도메인으로 지정된 경우에는 경로를 들어갈 수 있다. 즉, alb 경로는 해당 CDN을 들어갈 수 있다.
  2. 서버에서 CDN 사용하도록 설정
    1. Web001 서버에 접속하여 다음 파일을 수정합니다
    2. vi /var/www/html/image.html
      1. 기존 
        <img src='logo1.jpg' title='uuuuu' alt=''/>
      2. 변경 
        <img src='http://CDN접속정보/logo1.jpg' title='uuuuu' alt=''/>
  3. 이후 웹 브라우저에서 CDN 접속 정보로 접근
    1. http://lab-alb-100772604-447ccaf633a0.kr.lb.naverncp.com/logo1.jpg
    2. 이 경로는 접근 가능
  1. CDN 도메인으로 접근
  • http://gzjjrgjkdqqv27306021.gcdn.ntruss.com/logo1.png
  • 당연히 접속이 되지 않는다 → ReferredDomian으로 등록되지 않았기 때문이다.
