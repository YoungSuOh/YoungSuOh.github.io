Jenkins

  • 기본적으로 8080포트를 쓴다.
  • docker run -d -p 8080:8080 -p 50000:50000 —name docker-jenkins —restart=on-failue jenkins/jenkins:lts-jdk-17 
    docker run -d -p 8080:8080 -p 50000:50000 --name docker-jenkins --restart=on-failure jenkins/jenkins:lts-jdk17
    • Jenkins 서버를 Docker 컨테이너에서 실행하기 위한 명령어이다.
    • 세부 내용
      • docker run: 새 컨테이너를 생성하고 실행합니다.
      • d: 컨테이너를 백그라운드에서 실행합니다. 이 옵션이 없으면, 터미널에서 Jenkins 실행 로그가 계속 표시되지만, d를 사용하면 로그를 백그라운드에서 처리합니다.
      • p 8080:8080: 포트 매핑을 설정합니다. 호스트(로컬 머신)의 8080 포트를 컨테이너의 8080 포트에 연결합니다. Jenkins의 웹 인터페이스는 기본적으로 8080 포트에서 실행되므로, 이 매핑을 통해 브라우저에서 http://localhost:8080으로 Jenkins에 접근할 수 있습니다.
      • p 50000:50000: Jenkins에서 에이전트 연결을 위한 포트 매핑입니다. Jenkins의 슬레이브 에이전트들이 50000 포트로 연결됩니다.
      • -name docker-jenkins: 생성할 컨테이너의 이름을 **docker-jenkins*로 지정합니다. 이 이름을 통해 나중에 컨테이너를 관리할 수 있습니다.
      • -restart=on-failure: 만약 컨테이너가 오류로 종료되면, 재시작합니다. 단, 실패한 경우에만 재시작됩니다. 지속적인 실행을 보장하는 설정입니다.
      • jenkins/jenkins:lts-jdk-17: 사용할 이미지입니다. 이 경우, Jenkins의 LTS(Long Term Support) 버전으로, JDK 17이 포함된 Jenkins 이미지를 사용합니다.
    • 실행 목적
      • 이 명령어를 실행하면 Jenkins 서버가 Docker 컨테이너에서 실행됩니다.
      • 웹 인터페이스에 접근하려면, 브라우저에서 http://localhost:8080을 열면 됩니다.
      • Jenkins는 CI/CD 도구로, 소프트웨어 개발에서 빌드 자동화, 테스트, 배포 등을 관리하는 역할을 합니다.
      • 이 명령어는 개발 환경에서 Jenkins 서버를 쉽게 실행하고 테스트할 수 있는 방법입니다.
