학습 목표

  1. 내 서버 이미지 공유하기
  • Services >Compute>Server>Server image로 이동
  • web001-image 선택 후 상단의 공유 권한 설정
  • 강사가 지정한 수강생의 ID 를 입력 후 우측의 ‘권한 추가’ 클릭 > 하단의 ‘적용’ 클릭
