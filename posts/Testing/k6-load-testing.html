k6 테스트

k6 부하 테스트 도구의 기본 구조(init·setup·default·teardown)와 전역 변수(__ENV, __VU, __ITER), check·fail·group 등 핵심 API를 실전 예제와 함께 정리합니다.

Testingk6Load TestingPerformance

기본 구조

  1. Init Stage (스크립트 로드 시 1회 실행)
  2. setup() — 테스트 시작 전 1회 실행
  3. default() — 각 Virtual User가 반복 실행
  4. teardown() — 테스트 종료 후 1회 실행

예제

import http from 'k6/http';
import { check, sleep } from 'k6';

// 1. 테스트 옵션
export const options = {
  vus: 10,
  duration: '30s',
};

// 2. 테스트 시작 전 1회
export function setup() {
  console.log('테스트 준비');

  // 예: 로그인 토큰 발급
  const token = 'sample-token';

  return { token };
}

// 3. 각 VU가 반복 실행
export default function (data) {
  const res = http.get('https://test.k6.io', {
    headers: {
      Authorization: `Bearer ${data.token}`,
    },
  });

  check(res, {
    'status is 200': (r) => r.status === 200,
  });

  sleep(1);
}

// 4. 테스트 종료 후 1회
export function teardown(data) {
  console.log('테스트 종료');
}

k6가 제공하는 전역 변수 및 객체

1. __ENV — 환경 변수 읽기

k6 run -e로 전달한 값을 읽는 전역 객체

k6 run -e BASE_URL=http://localhost:8080 script.js

=================================

const BASE_URL = __ENV.BASE_URL || 'http://localhost:8090'; // 환경 변수 없으면 8090
console.log(BASE_URL); // "http://localhost:8080"

2. __VU — 현재 Virtual User 번호

  • 현재 실행 중인 가상 사용자 번호를 나타내는 전역 변수
  • 1부터 시작, 각 VU마다 고유
export const options = {
  vus: 3,
  iterations: 1,
};

export default function () {
  console.log(`현재 VU 번호: ${__VU}`);
}

// result
현재 VU 번호: 1
현재 VU 번호: 2
현재 VU 번호: 3

3. __ITER — 현재 반복 횟수

  • 현재 VU가 몇 번째 반복을 수행 중인지 나타내는 전역 변수
export const options = {
  vus: 1,
  iterations: 3,
};

export default function () {
  console.log(`VU=${__VU}, ITER=${__ITER}`);
}

// result
VU=1, ITER=0
VU=1, ITER=1
VU=1, ITER=2

4. export const options — k6 실행 설정 정의

export const options = {
  vus: 10,
  duration: '30s',
};

5. setup(), default(), teardown() — k6가 자동 호출하는 특수 함수

init stage
   ↓
setup()
   ↓
default()
   ↓
teardown()
  • setup() — 테스트 시작 전에 한 번 실행 
    export function setup() {
  return { token: 'abc123' };
}
  • default() — 각 VU가 반복 실행 
    export default function (data) {
  console.log(data.token);
}
  • teardown() — 테스트 종료 후 한 번 실행 
    export function teardown(data) {
  console.log('테스트 종료');
}

6. open() — 로컬 파일을 읽는 k6 전용 함수

// users.json
[
  { "email": "user1@test.com" },
  { "email": "user2@test.com" }
]

const users = JSON.parse(open('./users.json'));

7. check() — 응답 검증 함수

check(res, {
  'status is 200': (r) => r.status === 200,
});

8. fail() — 즉시 테스트 중단

import { fail } from 'k6';

if (res.status !== 200) {
  fail('요청 실패');
}

9. group() — 여러 요청을 논리적으로 묶음

import { group } from 'k6';

group('로그인', function () {
  // 로그인 요청
});

실전 예제

import http from 'k6/http';

const BASE_URL = __ENV.BASE_URL || 'http://localhost:8080';
const userEmail = `loaduser${__VU}@opay.test`;
const idempotencyKey = `approve-${__VU}-${__ITER}`;

export const options = {
  vus: Number(__ENV.VUS || '3'),
  iterations: 2,
};

export function setup() {
  return {
    token: 'sample-token',
  };
}

export default function (data) {
  console.log(
    `VU=${__VU}, ITER=${__ITER}, TOKEN=${data.token}`
  );

  http.get(`${__ENV.BASE_URL || 'http://localhost:8080'}/health`);
}

export function teardown() {
  console.log('done');
}

// command
k6 run -e VUS=3 -e BASE_URL=http://localhost:8080 script.js

// result
VU=1, ITER=0, TOKEN=sample-token
VU=1, ITER=1, TOKEN=sample-token
VU=2, ITER=0, TOKEN=sample-token
VU=2, ITER=1, TOKEN=sample-token
VU=3, ITER=0, TOKEN=sample-token
VU=3, ITER=1, TOKEN=sample-token
  • export default function의 파라미터 data는 k6가 setup()의 반환값을 자동으로 전달한 것
  • 즉, data === setup()의 return 값이라고 이해하면 된다.
