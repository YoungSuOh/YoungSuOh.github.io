[TDD] @Mock

@Mock 어노테이션으로 외부 의존성(DB, API)을 차단하고 테스트를 빠르고 독립적으로 만드는 이유와 사용법을 정리합니다.

TestingTDDMockitoUnit Test

@Mock은 테스트에서 가짜 객체(Mock 객체)를 만들어서 의존성을 통제하기 위한 도구이다.

✅ 핵심 요약

  1. 실제 객체 대신 가짜 객체 생성
  2. 외부 의존성(DB, API 등)을 차단하고 테스트를 빠르게/독립적으로 수행

🤔 왜 쓰나?

class CommentService {
    private FanEventRepository repo;

    public void save() {
        repo.save(...); // 실제 DB 접근
    }
}
  • 이 상태로 테스트하면…
    • DB 연결 필요
    • 느림
    • 테스트가 환경에 의존함

👍 해결: @Mock 사용

  • 실제 DB 접근 ❌
  • 가짜 객체 생성됨
  • 호출 여부 / 반환값 / 예외를 내가 컨트롤 가능
