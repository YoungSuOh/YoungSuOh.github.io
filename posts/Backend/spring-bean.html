[Spring] Spring Bean

Spring Bean은 Spring 컨테이너가 관리하는 객체를 의미한다.

SpringBeanDIScope

Spring 애플리케이션에서는 보통 객체를 직접 생성하지 않고, Spring 컨테이너가 객체를 생성·관리하고 필요할 때 주입하도록 사용한다.

Spring Bean의 특징

  1. Spring 컨테이너가 생성 및 관리
    개발자가 new 키워드로 직접 만들기보다 컨테이너가 Bean을 관리한다.
  2. 싱글톤(Singleton) 기본 적용
    기본적으로 Bean은 싱글톤으로 생성되어 애플리케이션에서 공유된다.
  3. 의존성 주입(Dependency Injection, DI) 지원
    @Autowired 등으로 다른 Bean을 주입할 수 있다.
  4. 라이프사이클 관리
    @PostConstruct, @PreDestroy로 생성/종료 시점을 제어할 수 있다.

Spring Bean 등록 방법

  1. @Component 기반 등록
    @Component, @Service, @Repository, @Controller 사용 시 자동 등록
  2. @Bean 기반 등록 (Java Config) 
    @Configuration
public class AppConfig {
    @Bean
    public MyComponent myComponent() {
        return new MyComponent();
    }
}
  3. XML 기반 등록 (예전 방식)

    applicationContext.xml을 생성해 Namespaces 및 Bean 정의를 작성한다.

    예시 클래스

    public class MessageBeanEn implements MessageBean {
    public MessageBeanEn() {
        System.out.println("MessageBeanEn의 기본 생성자");
    }
    @Override
    public void sayHello(String name) {
        System.out.println("Hello " + name);
    }
}

public class MessageBeanKo implements MessageBean {
    public MessageBeanKo() {
        System.out.println("MessageBeanKo의 기본 생성자");
    }
    @Override
    public void sayHello(String name) {
        System.out.println("안녕 " + name);
    }
}

    빈 등록

    <?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd
       http://www.springframework.org/schema/context http://www.springframework.org/schema/context/spring-context-4.3.xsd">
    <bean id="messageBeanEn" class="sample01.MessageBeanEn"/>
    <bean id="messageBeanKo" class="sample01.MessageBeanKo"/>
</beans>

    빈 호출

    public class HelloSpring {
    public static void main(String[] args) {
        ApplicationContext context = new ClassPathXmlApplicationContext("applicationContext.xml");

        MessageBean messageBean1 = (MessageBean) context.getBean("messageBeanEn");
        messageBean1.sayHello("spring1");

        MessageBean messageBean2 = (MessageBean) context.getBean("messageBeanKo");
        messageBean2.sayHello("spring2");
    }
}

Spring Bean 사용 방법

  1. @Autowired를 사용한 DI 
    @Component
public class MyService {
    private final MyComponent myComponent;

    @Autowired
    public MyService(MyComponent myComponent) {
        this.myComponent = myComponent;
    }

    public void execute() {
        myComponent.doSomething();
    }
}
  2. ApplicationContext에서 직접 가져오기 
    public static void main(String[] args) {
    ApplicationContext context = new AnnotationConfigApplicationContext(AppConfig.class);
    MyComponent myComponent = context.getBean(MyComponent.class);
    myComponent.doSomething();
}

    대부분의 경우에는 @Autowired 기반 DI를 권장한다.

Spring Bean의 라이프사이클

  1. 객체 생성
  2. 의존성 주입 (@Autowired)
  3. 초기화 메서드 실행 (@PostConstruct)
  4. 사용
  5. 소멸 전 메서드 실행 (@PreDestroy)
  6. Bean 소멸
@Component
public class MyComponent {

    @PostConstruct
    public void init() {
        System.out.println("Bean이 생성되었습니다!");
    }

    @PreDestroy
    public void destroy() {
        System.out.println("Bean이 소멸됩니다!");
    }
}

@PostConstruct는 생성 직후, @PreDestroy는 소멸 직전에 실행된다.

Bean Scope

Spring은 기본적으로 Singleton 스코프를 사용하며, 상황에 따라 다른 스코프를 선택할 수 있다.

  • Singleton (@Scope("singleton"))
    컨테이너당 하나의 인스턴스를 공유한다.
  • Prototype (@Scope("prototype"))
    요청할 때마다 새 객체를 생성한다.
  • Request (@Scope(value = WebApplicationContext.SCOPE_REQUEST))
    HTTP 요청 단위로 인스턴스를 제공한다.
  • Session (@Scope(value = WebApplicationContext.SCOPE_SESSION))
    세션 동안 동일 인스턴스를 유지한다.
  • Application (@Scope(value = WebApplicationContext.SCOPE_APPLICATION))
    애플리케이션 전역에서 공유한다.
  • WebSocket (@Scope("websocket"))

등록 방법

  1. @Scope 어노테이션 
    @Component
@Scope("singleton") // 기본값
public class SingletonBean {
    public SingletonBean() {
        System.out.println("Singleton Bean 생성됨!");
    }
}
  2. XML 설정 
    <?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd
       http://www.springframework.org/schema/context http://www.springframework.org/schema/context/spring-context-4.3.xsd">
    <bean id="messageBeanEn" class="sample01.MessageBeanEn"/>
    <bean id="messageBeanKo" class="sample01.MessageBeanKo" scope="prototype"/>
</beans>
  3. component-scan과 함께 사용 
    <?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd
       http://www.springframework.org/schema/context http://www.springframework.org/schema/context/spring-context-4.3.xsd">
    <context:component-scan base-package="sample01"/>
</beans>
