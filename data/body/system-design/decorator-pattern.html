한 줄 정의

기존 객체를 다른 객체로 감싸(wrap) 기능을 동적으로 추가하는 패턴.

문제 상황

  • 기능 조합이 많아 상속으로는 클래스가 폭증할 때
  • 런타임에 기능을 켜고 끄고 싶을 때

구성 요소

  • Component: 공통 인터페이스
  • ConcreteComponent: 기본 동작
  • Decorator: Component를 포함하고 기능 확장

Java 예제

interface Notifier {
    void send(String msg);
}

class BasicNotifier implements Notifier {
    public void send(String msg) { System.out.println("email: " + msg); }
}

abstract class NotifierDecorator implements Notifier {
    protected final Notifier delegate;
    protected NotifierDecorator(Notifier delegate) { this.delegate = delegate; }
}

class SmsDecorator extends NotifierDecorator {
    SmsDecorator(Notifier delegate) { super(delegate); }
    public void send(String msg) {
        delegate.send(msg);
        System.out.println("sms: " + msg);
    }
}

장점 / 단점

  • 장점: 조합 가능한 확장, 상속 클래스 폭증 방지
  • 단점: 데코레이터 계층이 깊어지면 디버깅이 어려울 수 있음

실무 포인트

  • Spring AOP의 프록시 기반 부가 기능(트랜잭션/로깅)과 개념적으로 유사
  • I/O 스트림 체인(BufferedInputStream)도 대표적 사례
