Maven

  • XML(pom.xml) 기반으로 선언적이고 직관적이지만, 설정이 길어질 수 있다.
  • mvn package, mvn install 같은 명령으로 빌드 과정이 단순하다.
  • Java, Spring 프로젝트에서 널리 사용된다.

pom.xml

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
        <version>3.0.0</version>
    </dependency>
</dependencies>

Gradle 특징

  • Groovy/Kotlin DSL 기반(build.gradle)으로 더 간결한 문법을 제공한다.
  • Spring Boot 2.5+ 프로젝트에서는 Gradle을 더 추천하는 경우가 많다.

build.gradle

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web:3.0.0'
}
