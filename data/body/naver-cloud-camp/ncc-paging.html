      • ref는 게시물 그룹 번호로, 일반적으로 원글과 답글을 묶는 역할을 한다. 즉, 하나의 원글과 그에 달린 모든 답글이 동일한 ref 값을 가진다.
        • ref desc는 최신 원글을 먼저 가져오는 방식이다.
      • step은 답글의 순서를 의미한다. 같은 ref 값을 가진 게시물들 중에서, 어떤 답글이 먼저 작성되었는지를 나타낸다.
        • step asc 은 같은 그룹 내에서 답글을 시간 순서대로 정렬하는 방식이다.
      • 이때, rownum은 Oracle 데이터베이스에서 제공하는 예약어이다.

    • makePagingHTML() 
      public void makePagingHTML() {
        pagingHTML = new StringBuffer();

        int totalP = (totalA + (pageSize - 1)) / pageSize;
        int startPage = (currentPage - 1) / pageBlock * pageBlock + 1;
        int endPage = startPage + pageBlock - 1;
        if (endPage > totalP) endPage = totalP;

        if (startPage > 1) {
            pagingHTML.append("<span id='paging' onclick='boardPaging(" + (startPage - 1) + ")'>이전</span>");
        }
        
        for (int i = startPage; i <= endPage; i++) {
            if (i == currentPage) 
                pagingHTML.append("<span id='currentPaging' onclick='boardPaging(" + i + ")'>" + i + "</span>");
            else 
                pagingHTML.append("<span id='paging' onclick='boardPaging(" + i + ")'>" + i + "</span>");
        }
        
        if (endPage < totalP) 
            pagingHTML.append("<span id='paging' onclick='boardPaging(" + (endPage + 1) + ")'>다음</span>");
    }
