학습 목표

  1. SubAccount에 조직도 반영
  2. Cloud Insight에 조직도 반영
  3. Cloud Insight에 Inxsvt1에 대해 CPU 사용률이 80%를 넘으면 서버팀에 알람이 가도록 설정

SubAccount 구성

  • Services >Management&Governance >SubAccount >SubAccounts에서 [+서브계정생성] 선 택 후 4명의 정보를 입력합니다.
  • 생성 완료
  • Services >Management >SubAccount > Groups에서 [+그룹생성 ] 을 선택하여 조직을 생성
  • 서버 운영팀, 네트워크 운영팀 2개 생성
  • 서버운영팀을 선택하고 서브계정의 [추가] 를 선택합니다. 그리고 홍길동, 허준을 선택한다.
  • 정책탭으로 이동해서 개별 권한 추가 클릭
  • 연관 서비스로 server를 검색하고 server(VPC)를 클릭한다.
  • 이후 관련된 모든 정책을 모두 추가한다.
  • 네트웍운영팀에는 유명인과 김철수를 추가하고 위 과정과 동일하게 연관서비스로 ‘VPC(VPC)’로검색하고 관련 정책을 모두 추가한다.
  • aaa로 로그인하기 위해 다른브라우저로 https://www.ncloud.com/nsa/설정한 접속페이지를 접근한다.
  • 이후 aaa로 로그인하여 콘솔을 열어 권한을 확인합니다.
    • server-ops에 배정된 것을 확인할 수 있다.

모니터링 사용자 구성

  • Services > Notification Recipient에서 대상자 그룹에 + 를 눌러 조직을 추가한다.
  • 조직은 서버팀, 네트웍팀 2개를 생성한다.

서버 모니터링 구성

  • Services >Management&Governace >CloudInsight >Configuration >EventRule에서 [+Event Rules 생성] 을 선택한다
  • 감시 상품 선택에서 Server(VPC)를 선택 후 하단의 ‘다음’ 버튼을 클릭한다.
  • 그룹 이름에 NCP Web Server 를 입력하고 web001과 web002를 대상으로 설정한다.
  • 설정 후 하단의 ‘생성’ 버튼을 클릭한다.
  • 템플릿 이름에 NCP Web Server CPU라고 입력한다.
  • 항목 탭에서 Server를 선택한 다음 Server/avg_cpu_userd_rto를 선택 후 하단의 ‘다음’ 버튼을 클릭한다.
  • 조건 설정 화면에서 아래와 같이 선택
    • 디멘샨 : all
    • 레젤 : warning
    • 조건 : >80
    • 집약 방법 : avg
    • 지속시간 : 1
    • 하단의 ‘저장’ 버튼을 클릭
  • 통보 대상자로 서버팀을 선택하고 다음을 클릭한다.
  • 룰 이름은 NCP Web Server CPU라고 입력한 후, 하단의 ‘생성’ 버튼을 클릭
