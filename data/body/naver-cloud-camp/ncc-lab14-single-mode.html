학습 목표

  1. 싱글모드로 부팅

싱글 모드 부팅을 사용하는 이유

  • 서버 부팅 시 오류 발생
    • 주된 원인 : fstab 오류, 파일 시스템 오류
    • 파일 시스템의 경우 부팅 시퀀스 상 매우 높은 순위로 먼저 실행됨
  • Root 패스워드 분실 시
    • 로그인 할 수 없는 경우
  • 장애 발생 시 조치 방법
    • 부트로더에서 싱글모드로 부팅

싱글 모드 진입

  • Server에서 web001 선택 후 상단의 재시작 선택
  • 웹 콘솔로 진입
  • 커널 버전 선택 화면에서 ‘e’ 입력하여 파라미터 수정 화면으로 진입
  • Linux 문장의 맨 마지막에 “rd.break” 추가 후 Ctrl+X로 부팅 시작
  • 싱글 모드 진입 -완-
