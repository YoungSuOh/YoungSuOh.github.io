도커 설치

SSH 접속을 완료했으면 도커를 설치해보자

  • apt-get update
    • apt-get update는 Debian 기반의 리눅스 배포판(Ubuntu, Debian 등)에서 사용되는 패키지 관리 명령어로, 시스템에서 사용할 수 있는 패키지 목록을 업데이트하는 명령
    • 패키지 목록이 최신 상태로 업데이트되면, 이후에 apt-get install이나 apt-get upgrade 같은 명령을 실행할 때 최신 버전의 패키지를 설치하거나 업그레이드할 수 있��.
  • 도커를 설치하는 플러그 설치 
    curl https://get.docker.com>docker-install.sh
    • docker를 설치하는 스크립트를 다운로드하는 과정dlek
    • 설치 확인
  • 권한 변경 후 도커 설치 진행 
    chmod 755
./docker-install.sh
    • 도커 설치 완료
    • 도커 버전 확인

도커 실습

  • docker ps -a : 모든 Docker 컨테이너의 목록을 보여줌.
    • 다음 정보를 제공
      • 컨테이너 ID
      • 이미지 이름
      • 명령어
      • 생성 시간
      • 상태 (실행 중, 중지됨, 종료됨 등)
      • 포트 매핑
      • 컨테이너 이름
      • ex 
        $ docker ps -a
CONTAINER ID   IMAGE          COMMAND                  CREATED        STATUS                     PORTS         NAMES
abc12345       nginx:latest   "nginx -g 'daemon of…"   5 minutes ago   Exited (0) 3 minutes ago                 my-nginx
def67890       ubuntu:latest  "/bin/bash"              10 minutes ago  Up 9 minutes                             my-ubuntu
  • IMAGE → 냉동 식품
  • docker run hello-world : 냉동 해동
  • 이후 다시 docker ps -a
  • 도커 컨테이너 제거
    • docker rm {CONTAINER ID}
