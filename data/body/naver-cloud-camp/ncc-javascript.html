변수 자료형

let, var, const가 존재한다.

  1. let
    1. 지역 변수, 구역 단위 변수이다.
    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
    <script type="text/javascript">
        // 지역 단위, 구역 단위
        let a = 100;
        a = 250;
        console.log(a);  // F12 -> 콘솔 => 250이 찍힘
        {
            let a = 200;
            console.log(a);  // F12 -> 콘솔 => 그 다음에 200이 찍힘
            {
                let a = 300;
                console.log(a);  // F12 -> 콘솔 => 그 다음에 300이 찍힘
            }
            console.log(a);  // 200 찍힘
        }
        console.log(a); // 250 찍힘 -> 지역 변수의 특성 반영
    </script>
</head>
<body>

</body>
</html>

객체

  • 변수와 함수의 집합
  • Javascript는 Prototype 기반의 객체지향언어이다. 객체를 원형(prototype) 형태로 생성하고, 그 안에 기능을 위한 변수나 함수를 추가하는 방법으로 그룹화 하는 개념
  • 객체는 자주 사용하게 될 기능들을 묶어서 외부의 스크립트 파일로 분리해 내는 용도로 주로 사용한다.
  • 이렇게 만든 스크립트 파일은 여러개의 HTML파일에 의해서 참조하여 재사용할 수 있다.

isNaN(문자열)

  • 문자열이 숫자형식이 아니면 true, 숫자형식이면 false
  • isNaN 함수가 숫자가 아닌 값을 판별할 때, 그 값을 먼저 숫자로 변환하려고 시도한다 → 노오력이 가상한 함수
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>

<script>
    var a = Number("a");
    document.write("a = " + a + "<br>");  // NaN (not a number)

    var sum = a + 1;
    document.write("sum = " + sum + "<br>");  // NaN + 1 = NaN (not a number)

    var str = a + "str";
    document.write("str = " + str + "<br>");  // NaNstr

    var v1 = "가나다라";
    var v2 = "123456";  // isNaN 함수가 숫자가 아닌 값을 판별할 때, 그 값을 먼저 숫자로 변환하려고 시도한다 => 노오력이 가상한 함수네

    var is_num1 = !isNaN(v1);  // false
    var is_num2 = !isNaN(v2);  // true

    if (is_num1) {
        document.write(v1 + "는 숫자가 입니다.<br>");
    } else {
        document.write(v1 + "는 숫자가 아닙니다.<br>");
    }

    if (is_num2) {
        document.write(v2 + "는 숫자가 입니다.<br>");
    } else {
        document.write(v2 + "는 숫자가 아닙니다.<br>");
    }

    function sumInt(x,y) {
        var isStrX =! isNaN(x); // false
        var isStrY =! isNaN(y); // true

        if(!isStrX || !isStrY){
            return "숫자 형태이거나 숫자값이 전달되어야 한다."
    }

        var result = parseInt(x)+parseInt(y);
        return result;
    }
    document.write(sumInt("a",1)+"<br>");
    document.write(sumInt("1","2")+"<br>");
    document.write(sumInt(100,"5.6")+"<br>");
    document.write(sumInt(-1,"-100")+"<br>");
</script>
</body>
</html>

📄 이벤트 처리

특정한 상황이 발생했을 때, 사용자가 정의하는 특정한 동작(함수)들을 호출되도록 하는 것 Javascript를 사용하는 이유는 <body> 안의 어떠한 태그를 사용자의 이벤트에 반응하도록 제어하기 위함이다.

이벤트 종류

  1. onBlur - 문서나 윈도우, 프레임세트, 폼 요소에서 현재 입력 포커스가 사라질 때
  2. onClick - 링크, 이미지맵 영역, 폼 요소가 클릭되었을 때
  3. onFocus - 문서나 윈도우, 프레임세트, 폼 요소에서 현재 입력 포커스가 놓였을 때
  4. onLoad - 이미지, 문서, 프레임이 로드될 때
  5. onMouseOver - 태그의 요소 위로 마우스 커서가 들어갈 때
  6. onMouseOut - 태그의 요소 위에서 마우스 커서가 빠져나갈 때

제어대상 지정

  • 태그의 id로 제어할 특정 태그를 지정한다.
  • document.getElementById("아이디") 로 자바스크립트로 태그를 가져온다.

  1. concat : 배열 합치기

    let arr1 = [10,20,30]

  2. every : 배열의 모든 요소가 주어진 조건을 만족하는지 확인

let allPositive = numbers.every(function(num) {
    return num > 0;
});

let evens = numbers.filter(function(num) {
    return num % 2 === 0;
});
console.log(evens);  // [2, 4]

    let numbers = [1, 2, 3, 4, 5];
numbers.forEach(function(num) {

});
  5. indexOf : 배열에서 특정 요소를 찾고, 해당 요소의 첫 번째 인덱스를 반환. 요소가 배열에 없으면 -1을 반환

console.log(index2);  // 0 (사과는 첫 번째 인덱스에서 발견됩니다.)

let index3 = fruits.indexOf("수박");
console.log(index3);  // -1 (수박은 배열에 없습니다.)
  6. join : 배열을 문자열로 만들어라
    1. let join1 = arr1.join() → 구분자가 없으면 자동으로 콤마(,)가 들어간다.
    2. let join2 = arr1.join("|") -> 배열 요소 사이에 구분자( | )를 넣어서 문자열을 만든다.
  7. push & unshift : 배열 요소 추가
    1. push는 뒤에 추가
    2. unshift는 앞에 추가
  8. pop & shift
    1. pop은 뒤에 삭제 or 꺼내서 삭제한다의 개념

  9. splice : 배열의 기존 요소를 삭제하거나 교체하거나 새 요소를 추가하여 배열의 내용을 변경
    • 형식: splice(start, deleteCount, item1, item2, ...)
    • start: 시작 인덱스입니다. 이 위치에서부터 요소를 삭제하거나 추가합니다.
    • deleteCount: 제거할 요소의 개수입니다. 0이면 요소를 제거하지 않고, 단순히 요소를 추가합니다.
    • item1, item2, ...: 배열에 추가할 요소입니다. 이 인수는 선택적입니다
    let fruits = ["사과", "바나나", "딸기", "포도"];

// 요소 삭제

console.log(removed); // ["바나나", "딸기"]

// 요소 추가

console.log(fruits);  // ["사과", "망고", "수박", "포도"]

// 요소 교체
fruits.splice(2, 1, "키위");  // 인덱스 2의 요소를 "키위"로 교체

  10. slice : 배열의 일부를 추출하여 새로운 배열을 반환

    3. end: 추출이 끝나는 인덱스입니다. 이 인덱스는 포함되지 않습니다. 지정하지 않으면 배열의 끝까지 추출합니다

let slicedToEnd = fruits.slice(2);  // 인덱스 2부터 끝까지 추출
console.log(slicedToEnd);  // ["딸기", "포도", "키위"]

// 원본 배열은 그대로 유지

📄 브라우저 객체

브라우저에 내장된 객체를 의미. 계층적 구조를 가지며 BOM(Browser Object Model)라고도 한다.

자바 스크립트 객체 계층 구조

  • window : 최상위 객체, 브라우저 창이 열릴 때마다 하나씩 만들어진다. 브라우저 창안의 요소 중에서 최상위에 있다.
  • document : 웹 문서마다 하나씩 있으면, <body> 태그를 만나면 만들어진다. HTML 문서의 정보가 담겨 있다.
  • navigator : 현재 사용하는 브라우저의 정보가 들어있다.
  • location : 현재 페이지의 URL 정보가 담겨 있다.
  • screen : 현재 사용하는 화면 정보를 다룬다.

      • window.open(url,"아무 이름이나 사용","width=300, height=500, scrollbars=no, toolbar=no, menubar=no, status=no, location=no")
    • 깨알 정보
      • a태그에서 onclick이 있을 경우 onclick을 먼저 수행하고 href로 이동하는 액션을 취한다.
      • onclick에서 return false; 가 있을 경우 href로 이동하는 액션을 취하지 않게 된다. 
        <a href="http://www.naver.com/" onclick="alert('hi'); return false;">TEST2</a>
      • 만약 이렇게 되어있다면 
        <a href="#" onclick="alert('hi');">TEST1</a>
        • a태그에서 onclick이 있을 경우 onclick를 먼저 수행하고 href로 이동하는 액션을 취하는데, href="#" 로 호출 함수를 숨겨버렸지 때문에 페이지가 이동하지 않게 된다.
        • 갈 곳을 잃어버린 브라우저는 페이지의 상단으로 이동해버린다.

history 객체

  • 브라우저에서 [뒤로] 나 [앞으로] 또는 주소 표시줄에 입력해서 방문한 사이드 주소가 배열형태로 저장된다.
  • 브라우저 히스토리는 보안 문제로 인해 Read Only이다.
  • 예제 코드 
    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
    <h1>History 객체</h1>
    <a href="examHistory">페이지 이동</a>
    <a href="#" onclick="history.forward(); return false;">앞 페이지 이동</a>
</body>
</html>

location 객체

  • 이름에서도 알 수 있듯이 브라우저의 주소 표시줄과 관련이 있다.
  • 즉, location 객체에는 현재 문서의 URL 주소 정보가 들어 있는데, 이 정보를 편집하는 현재 브라우저 창에 열어야 할 사리으타 문서를 지정할 수 있다.
  • 메서드
    • assign : 현재 문서에 새 문서 주소를 할당해서 새 문서를 가져온다.
    • reload : 현재 문서를 다시 불러온다.
    • replace : 현재 문서의 URL을 지우고 다른 URL의 문서로 교체한다.
    • toString : 현재 문서의 URL을 문자열로 반환
  • 예시코드 
    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body onload="autoNo()">
    <p>
        고객님의 인증번호는 <strong id="auth">0000</strong>입니다.
    </p>

    <input type="button" value="인증번호 새로 받기" onclick="refresh()">
    <input type="button" value="네이버로 이동하기" onclick="goNaver()">

<script>
    function rand(x,y){
        return Math.floor(Math.random()*(y-x+1)+x)  // x~y 사이의 난수 발생시킴
    }
    function autoNo(){
        let value = "";
        for(let i=0;i<5;i++){
            value += rand(0,9)
        }
        document.getElementById("auth").innerText = value
    }
    function refresh(){
        location.reload()  // F5 키랑 똑같은 역할
    }
    function goNaver(){
        if(confirm("정말로 네이버로 이동하시겠습니까?")) location.href="https://naver.com"
    }
</script>
</body>
</html>

screen 객체

  • 웹 사이트에 접속하는 사용자의 화면 크기는 모두 다르므로 사용자의 화면 크기나 정보를 알아낼 때 screen 객체를 사용한다.
  • screen 객체에서 사용하는 메서드는 화면 방향을 잠그거나 잠근 화면의 방향을 해제하는 역할을 한다.
