학습 목표

  1. Cloud DB for Redis 생성 및 접속

Config group 생성

  • Services > Cloud DB for Redis > Config Group > Config Group 생성 클릭
  • Config group 생성

Redis 서버 생성

Redis 서버 접속

  • Cloud-redis의 ACG를 클릭하여 web 서버의 acg에 대하여 6379포트의 허용 정책을 적용
  • 생성한 CloudDB for Redis 서버에 접속을 해보자
wget http://download.redis.io/releases/redis-4.0.6.tar.gz && \
tar xvfz redis-4.0.6.tar.gz && \
cd redis-4.0.6 && \
make
  • Redis Client를 설치
  • Redis의 DNS 정보는 Redis Cluster를 선택한 후, 관리 > Redis설정에서 노드별로 확인할 수 있다.
  • Redis의 노드에 접속을 해보자.
  • 아래 명령어를 통해 Redis 노드에 접속을 하자
./redis-cli -c -h DNS명-p Redis접속포트
./redis-cli -c -h redisc-303rmh.vpc-cdb.ntruss.com -p 6379
  • 뤠디스 접속 성공 ^^

Redis에서 명령어 실습

  • 간단히 데이터 삽입
    • Redis에서는 데이터를 저장할 때 ‘set’ 명령어를 사용하며 ‘set[key값][Value]’로 데이터 삽입이 가능하다 
      set ncp ncpservice  // key value 형태로 redis에 저장

get ncp

get b

set b "Good-bye" EX 5 // 5초만 b에 "Good-bye"를 저장, 지나면 nil 됨

get b

get b // 5초뒤 실행
  • Cloud DB for Redis에서 저장된 모든 Key들을 검색할 수 있는 Keys 명령어를 입력해보자 
    keys *

위와 같이 ERR Unknown command라고 표기되며 실행되지 않습니다.

네이버 클라우드 플랫폼에서는 Cloud DB for Redis의 안정적인 운영을 위해 몇가지 명령어들에 대해서는 사용을 금지하고 있다.

아래의 명령어들은 사용이 불가능하다.
