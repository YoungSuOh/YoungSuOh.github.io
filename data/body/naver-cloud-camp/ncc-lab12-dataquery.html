  1. Data Query 서비스로 이동 및 서비스 신청
    1. Services > Big-data and Analytics > Data Query 클릭 (상품이용신청이안되어있다면상품이용신청부터진행)
    2. QueryEditor로 이동
    3. 상단의 ‘+데이터소스추가’ 클릭
    4. 우측 하단의 ‘커넥션’ 클릭 (‘커넥션’ 클릭 시 DataCatalog 서비스로 이동)
  2. Data Catalog를 통한 커넥션생성
    1. 상단의 ‘+커넥션생성’ 클릭
    1. 이름 : cdb-connection
    2. 데이터유형 : JDBC선택
    3. 접근URL : 아래의 형식에 맞추어 URL입력
    4. jdbc:mysql://(각자의 CDB for mysql Domain):3306/sakila?characterEncoding=utf8&autoReconnect=true 
      jdbc:mysql://db-302mqn-kr.vpc-pub-cdb.ntruss.com:3306/sakila?characterEncoding=utf8&autoReconnect=true
    5. ID :student
    6. 암호 : (CDB forMysql생성시입력했던비밀번호입력)
    7. 계정 정보 하단의 연결테스트’ 클릭
    8. 연결 테스트가 완료되면 하단의 ‘생성’ 버튼 클릭
  • Data query를 사용해서 데이터 조회
    • 데이터 소스 드롭 다운 메뉴에서 ‘cdb_query’ 선택
  • 우측의 쿼리 실행창 활성화, 데이터베이스는 ‘sakila’로 선택
  • 쿼리창에 아래 SQL문을 기입하여 데이터 조회
    • 예시 코드
    SELECT 
    CONCAT(first_name, ' ', last_name) AS full_name, 
    COUNT(film_id) AS film_count
FROM 
    actor
LEFT JOIN 
    film_actor USING (actor_id)
GROUP BY 
    first_name, last_name
ORDER BY 
    film_count DESC
LIMIT 10;
  • 실행 구조도 탭 클릭 시 각SQL문이 실행되었을 시에 사용하는 스캔데이터 크기, 메모리 최대 사용 량 등 상세한 정보 확인이 가능
