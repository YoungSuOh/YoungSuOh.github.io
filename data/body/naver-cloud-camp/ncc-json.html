JSON (JavaScript Object Notation)은 데이터를 구조화된 형태로 저장하고 전송하기 위해 사용되는 경량 데이터 교환 형식이다.

특징

  • 텍스트 기반 형식: JSON은 텍스트 기반이기 때문에 쉽게 읽고 쓸 수 있습니다. 이로 인해 다양한 프로그래밍 언어에서 지원됩니다.
  • 키-값 쌍: JSON의 데이터 구조는 키-값 쌍의 집합으로 이루어져 있습니다. 이 키는 문자열로 표현되며, 값은 문자열, 숫자, 배열, 객체, true, false, null 등의 자료형을 가질 수 있습니다.
  • 중첩 구조: JSON은 중첩된 구조를 가질 수 있습니다. 객체 안에 객체나 배열을 포함할 수 있으며, 배열 안에 객체를 포함할 수도 있습니다.
  • 언어 독립성: JSON은 특정 프로그래밍 언어에 종속되지 않으며, 여러 언어에서 쉽게 파싱하고 생성할 수 있습니다.
