Scope

JSP에서 스코프(scope)는 웹 애플리케이션 내에서 객체가 존재하는 범위와 생명주기를 정의한다.

pageScope → requestScope → sessionScope → applicationScope 순으로 호출된다

  1. pageScope
    1. 범위: 현재 JSP 페이지 내
    2. 생명주기 : 페이지가 실행되는 동안만 객체가 유지됩니다. 다른 페이지로 이동하거나 요청이 넘어가면 객체는 사라집니다.
  2. requestScope
    1. 범위: 하나의 요청(request) 동안
    2. 생명주기: 클라이언트가 요청한 페이지 내에서 또는 forward나 include로 다른 페이지에 데이터를 넘길 때까지 객체가 유지됩니다
  3. sessionScope
    1. 범위: 사용자 세션 전체
    2. 생명주기: 사용자가 웹 서버에 접속해서 세션이 종료될 때까지 객체가 유지됩니다
  4. applicationScope
    1. 범위: 웹 애플리케이션 전체
    2. 생명주기: 서버가 시작되고 종료될 때까지 객체가 유지됩니다.

스코프에 대한 오해

request나 response 객체는 문자열과 같은 단순한 데이터뿐만 아니라 객체도 전달할 수 있습니다. 예를 들어, request.setAttribute("list", list);와 같이 ArrayList 같은 객체도 request 스코프를 통해 다른 JSP 페이지에 전달할 수 있습니다.
