1. Object Storage 사용을 위한 fuse 구성

  • Services >Storage >ObjectStorage 선택 >+버킷생성선택
  • 버킷 이름에 ‘네이버클라우드플랫폼아이디-fuse’ 버킷 생성
    • 설정 관리 및 암호화 설정, 권한 관리는 디폴트 값으로 두고 생성 진행
  • Web001에 접속하여 패키지 설치
    • 패키지 설치 명령어
      • https://kr.object.ncloudstorage.com/ai-edu/s3fuse.txt
yum install automake fuse-devel gcc-c++ git libcurl-devel libxml2-devel make openssl-devel -y
git clone https://github.com/s3fs-fuse/s3fs-fuse.git
cd s3fs-fuse
./autogen.sh
./configure
make
make install
  • 마운트 포인트 생성

    • 각자의 accesskey와 secretkey값은 마이페이지>인증키관리에서 확인 가능
    echo ACCESS_KEY_ID:SECRET_ACCESS_KEY > /etc/passwd-s3fs
chmod 600 /etc/passwd-s3fs
    echo 0389DFB99F746878DB12:050CE19EB83E86EEDD7EA995DB392AEE59CC3D1A > /etc/passwd-s3fs
chmod 600 /etc/passwd-s3fs

백업 서비스 신청하기

리소스 생성

  1. 메뉴 이동:

    Services > Storage > Backup 선택

    Backup > Resource 메뉴로 이동

  2. 리소스 생성:

    상단의 ‘리소스 생성’ 클릭

    • 리소스 이름: nce-backup
    • 존: KR-2
    • 서버: web002
    • 에이전트 유형: Data
    • 아이디: root (백업 서비스 수행을 위해 root 권한 필요)
    • 비밀번호: root 계정 비밀번호 입력하단의 ‘다음’ 버튼 클릭
  3. 생성 확인:

    마지막 최종 페이지 확인 후 하단의 ‘리소스 생성’ 클릭

저장소 생성

  1. 메뉴 이동:

    Backup > Storage 클릭

  2. 저장소 생성:

    ‘저장소 생성’ 클릭

    • 저장소 이름: nce-backup
    • 존: KR-2 선택하단의 ‘다음’ 버튼 클릭 > 하단의 ‘생성’ 클릭

정책 생성

  1. 메뉴 이동:

    Backup > Policy 클릭

  2. 정책 생성:

    상단의 ‘정책 생성’ 클릭

    • 정책 이름: nce-policy
    • 보관 기간: 7일
    • 존: KR-2하단의 ‘다음’ 클릭 > ‘생성’ 클릭

작업 생성

  1. 메뉴 이동:

    Backup > Job 클릭

  2. 작업 생성:

    ‘작업 생성’ 클릭

    • 작업 이름: nce-job
    • 리소스: nce-backup
    • 백업 대상 유형: Data
    • 백업 대상 경로: /root
    • 정책: nce-policy 선택하단의 ‘다음’ 클릭 > ‘생성’ 클릭

일정 생성

  1. 메뉴 이동:

    Backup > Schedule 클릭

  2. 일정 생성:

    상단의 ‘일정 생성’ 클릭

    • 일정 이름: nce-backup-schedule
    • 작업: nce-job
    • 백업 방식: 전체
    • 백업 주기: 일간
    • 시작 시간: AM 10:00하단의 ‘다음’ 버튼 클릭 > ‘생성’ 클릭
