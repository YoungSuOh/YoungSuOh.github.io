1. JAR (Java ARchive) 파일

  • JAR 파일은 여러 개의 Java 클래스 파일, 메타데이터 및 관련 리소스를 하나로 묶은 압축 파일이야. Java 응용 프로그램이나 라이브러리를 배포하기 위해 사용돼.
  • 용도
    • 보통 데스크톱 애플리케이션이나 Java 라이브러리를 배포할 때 사용해. 예를 들어, 독립 실행형 프로그램이나 여러 프로젝트에서 공유하는 유틸리티 클래스들을 JAR 파일로 묶어 사용할 수 있어.
  • 구조
    • JAR 파일은 일반 ZIP 압축 형식으로 되어 있어서 쉽게 압축을 풀 수 있어. META-INF 디렉토리 안에 MANIFEST.MF라는 메타데이터 파일이 포함되어 있어, 이 파일에 프로그램의 주요 정보(예: 메인 클래스)가 기록돼.
  • 실행
    • JAR 파일이 독립 실행형 애플리케이션일 경우 java -jar 파일명.jar 명령어로 실행할 수 있어. MANIFEST.MF에 메인 클래스 정보가 지정돼 있어야 실행이 가능해

2. WAR (Web Application Archive)

  • WAR 파일은 Java 기반의 웹 애플리케이션을 배포하기 위해 사용되는 아카이브 파일이야. JSP, 서블릿, HTML 파일, 자바스크립트, 이미지, 그리고 웹 애플리케이션을 구성하는 모든 리소스가 포함돼.
  • WAR 파일은 주로 웹 서버나 애플리케이션 서버에 배포할 때 사용해. 예를 들어, Tomcat, JBoss 같은 서버에서 실행되는 웹 애플리케이션을 WAR 파일로 패키징해 배포할 수 있어.
  • 구조: WAR 파일에는 특정 디렉토리 구조가 요구돼.
    • WEB-INF/: 서버가 처리할 파일을 담고 있으며, JSP와 서블릿 정보, 설정 파일(web.xml) 등이 위치해.
    • WEB-INF/classes: 컴파일된 클래스 파일들이 위치해.
    • WEB-INF/lib: 필요한 라이브러리 JAR 파일들이 위치해.
  • 배포 및 실행
    • WAR 파일은 웹 애플리케이션 서버의 특정 디렉토리에 복사하거나 관리 콘솔을 통해 업로드함으로써 실행할 수 있어. 서버가 자동으로 WAR 파일을 풀고 웹 애플리케이션을 실행해.

한마디로 정리

  • JAR 파일: 데스크톱 애플리케이션이나 라이브러리 패키징용
  • WAR 파일: 웹 애플리케이션 배포용
