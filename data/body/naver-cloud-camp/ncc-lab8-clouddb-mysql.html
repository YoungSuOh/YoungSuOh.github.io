Cloud DB for MySQL 이벤트 설정하기

  • Cloud DB for MySQL 메뉴에 Event 메뉴를 클릭
  • Event Rule(Cloud Insight) 설정 클릭
  • Cloud DB For MySQL(VPC) 선택 후 하단의‘ 다음’ 버튼 클릭
  • 그룹 생성
  • 템플릿 생성
  • 이름 : edu-cdb-template
  • Metric : cpu_load1, mysql_slow 선택
  • 아래와 같이 임계치를 설정 후, 하단의 ‘저장’ 버튼 클릭
    • Cpu_load_1 / 디멘션 : all / level : critical / condition>=30 / method=avg / duration:10
    • mysql-slow / 디멘션 : all /level : critical / condition>=10/method=avg / duration:10
  • edu_cdb_template 선택 후, 하단의 ‘다음’ 클릭
  • 통보 대상자 오영수 설정

Cloud DB for MySQL DB Fail-over 테스트하기

Fail-Over란?

Fail-Over는 시스템, 서버, 네트워크 등에서 문제가 발생했을 때, 서비스를 중단하지 않고 자동 또는 수동으로 대체 시스템으로 전환하는 프로세스를 의미해. 주로 고가용성(High Availability)을 유지하고, 장애로 인한 서비스 중단을 최소화하기 위해 사용돼.

  • Fail-over를 테스트할 서버를 선택한 후에 상단의 DB관리 메뉴에서 MasterDB Fail-over 메뉴를 클릭
  • 다음과 같이 Event 탭에서 Failover를 확인할 수 있으며, 현재 Active Master의 노드도 확인 가능
  • 진행중
