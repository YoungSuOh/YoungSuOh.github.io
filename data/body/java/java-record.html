DTO 객체를 훨씬 간결하게 만들기 위해 나온 문법.

✅ 핵심 한 줄

Record = 필드 + 생성자 + getter + equals/hashCode/toString을 자동 생성해주는 불변 데이터 클래스

기본 문법

public record User(String name, int age) {}

이 한 줄이 사실상 아래 클래스를 의미한다.

public final class User {
    private final String name;
    private final int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String name() { return name; }
    public int age() { return age; }

    // equals, hashCode, toString 자동 생성
}

✅ 특징

  1. 불변 객체 — 모든 필드는 final, setter 없음 (상태 변경 ❌)
  2. 자동 생성 — 생성자, getter(), equals(), hashCode(), toString()
  3. 상속 제한 — Record는 다른 클래스를 상속받을 수 없고, 자동으로 final이므로 다른 클래스가 상속받을 수도 없음

실무 사용 예시

보통 다음처럼 DTO에 많이 쓰인다.

public record CreateUserRequest(String name, int age) {}
