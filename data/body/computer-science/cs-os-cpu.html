CPU (Central Processing Unit)
컴퓨터의 중앙처리장치로, 프로그램 명령을 해석하고 실행하는 컴퓨터의 두뇌. 모든 연산과 제어가 이곳에서 일어난다.

🧠 CPU 내부 구조도

구성 요소 상세

CU
제어 장치 (Control Unit) — 명령어를 해석하고 ALU·레지스터에 명령을 전달, 실행 흐름 제어 (Fetch·Decode·Execute)
ALU
산술 논리 장치 (Arithmetic Logic Unit) — 산술 연산(+, −, ×, ÷)과 논리 연산(AND, OR, NOT)을 수행
Register
CPU 내부의 고속 데이터 저장소. PC(다음 명령어 주소), IR(현재 명령어), 범용 레지스터
Clock
CPU 동작 속도를 결정. 클록 주파수(Hz)가 높을수록 빠름
Cache
CPU와 메모리 간 속도 차를 줄이는 고속 임시 저장소
Bus
데이터 버스, 주소 버스, 제어 버스

🔄 명령어 사이클 (Instruction Cycle)

CPU는 단순한 사이클을 끝없이 반복하며 모든 작업을 처리한다.

🔁
이 사이클이 1초에 수십억 번 반복된다 — 3GHz CPU = 초당 30억 사이클. CPU의 모든 동작은 이 단순한 사이클의 누적이다.

📦 명령어 세트 (Instruction Set)

CPU가 이해할 수 있는 기본 명령어들의 집합. 기계어로 표현되며 CU가 해독한다.

연산
ADD, SUB, MUL, DIV
제어
JUMP, CALL, RETURN
데이터 전달
LOAD, STORE, MOV
입출력
IN, OUT

🎬 실전 예시: C = A + B 실행 과정

⚡ CPU 성능 결정 요소

🏎️ 멀티코어와 병렬 처리

싱글 코어
하나의 작업만 처리. 다른 작업은 컨텍스트 스위칭으로 시분할
멀티 코어
여러 코어가 진짜 동시에 작업 처리. 각 코어가 독립된 ALU·CU·레지스터를 가짐
⚠️
한계: 모든 작업이 병렬화 가능한 건 아니다 (암달의 법칙). 순차 의존성이 있는 작업은 멀티코어의 이점을 누리기 어렵다.

요약

본질
CPU는 Fetch-Decode-Execute 사이클을 무한 반복하는 단순한 기계
구성
CU(제어), ALU(연산), 레지스터(저장), 캐시(가속), 클럭(타이밍), 버스(통신)
성능
클럭 × 코어 수 × 캐시 효율 × 아키텍처(ISA)의 종합
한계
클럭은 발열로 정체 → 멀티코어로 진화 → 모든 작업이 병렬화 가능한 건 아님 (암달의 법칙)
핵심: 단순한 사이클의 반복이지만 초당 수십억 번 일어나기에 우리가 보는 모든 디지털 세상이 가능하다.
