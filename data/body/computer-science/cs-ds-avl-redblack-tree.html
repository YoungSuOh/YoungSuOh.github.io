AVL Tree

AVL Tree
높이 균형 트리. 모든 노드에서 왼쪽·오른쪽 서브트리 높이 차이가 최대 1 유지. 삽입·삭제 시 균형 맞춰 O(log n) 유지

균형 조건

⚖️
Balance Factor = 왼쪽 높이 - 오른쪽 높이. |BF| ≤ 1을 항상 만족

삽입 시 회전(Rotation) 유형

LL
오른쪽 회전
RR
왼쪽 회전
LR
왼쪽 → 오른쪽 회전
RL
오른쪽 → 왼쪽 회전
장점
탐색 빠름 O(log n), 높이 낮음
단점
삽입/삭제 시 회전 많음, 균형 유지 비용

Red-Black Tree

Red-Black Tree
균형 이진 탐색 트리. 완벽한 균형은 아니지만 평균적 균형 유지 → O(log n) 보장. 삽입/삭제 균형 비용이 AVL보다 적음

5가지 규칙

  1. 노드는 빨강 또는 검정
  2. 루트는 항상 검정
  3. 모든 리프(NIL)는 검정
  4. 빨강 노드는 연속될 수 없음 (Red-Red 불가)
  5. 모든 경로에서 검정 노드 개수 동일 (Black Height 유지)

삽입/삭제

삽입
BST 규칙 + 삽입 노드는 항상 빨강 + 속성 위반 시 Color Flip 또는 Rotation
삭제
BST 삭제 + 검정 노드 삭제 시 속성 확인 + 균형 유지
장점
삽입/삭제 AVL보다 빠름, 회전 적음, 메모리 오버헤드 적음
단점
탐색은 AVL보다 느림 (높이가 더 큼), 구현 어려움
결론: AVL = 탐색 속도 최적화 / Red-Black = 삽입·삭제 속도 최적화
