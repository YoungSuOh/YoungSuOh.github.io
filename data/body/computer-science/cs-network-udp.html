UDP
User Datagram Protocol. 데이터를 데이터그램 단위로 처리하는 비연결형·신뢰성 없는 전송 프로토콜

TCP와 UDP 등장 배경

IP는 Host-to-Host만 지원 → 하나의 장비 내 수많은 프로그램 통신에는 한계 → 포트 번호 등장

IP 오류는 ICMP가 알리지만 대처 불가 → TCP/UDP 등장

TCP
분실·중복·순서 뒤바뀜을 자동 보정하여 정확한 전달
UDP
IP가 제공하는 정도. 에러·재전송·순서 뒤바뀜은 애플리케이션에서 처리

UDP는 왜 사용?

⚡
데이터의 신속성. 실시간 방송, 온라인 게임에서 사용. 네트워크 안 좋을 때 끊기는 현상이 UDP 특성

DNS에서 UDP 사용 이유

  • Request 양이 작아 UDP Request에 담길 수 있음
  • 3 way handshake 연결 유지 불필요 (오버헤드)
  • Request 손실은 Application Layer에서 제어 가능
  • DNS port: 53번
  • 예외: 크기가 512(UDP 제한)를 넘으면 TCP 사용
