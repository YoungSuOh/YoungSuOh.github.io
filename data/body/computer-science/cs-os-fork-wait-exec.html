4가지 시스템 콜

fork()
새로운 프로세스 생성. parent ← child의 pid, child ← 0
wait()
자식 프로세스 종료까지 대기. 좀비 프로세스 방지
execl(path, arg, ..., NULL)
현재 프로세스를 다른 프로그램으로 교체. 절대/상대 경로 지정
execlp(file, arg, ..., NULL)
execl과 동일하지만 $PATH에서 파일 검색

예제 1: fork() + wait()

pid_t pid = fork();
if (pid > 0) {           // 부모
  wait(NULL);
  printf("자식 종료됨\n");
} else if (pid == 0) {   // 자식
  printf("자식 실행 중\n");
  sleep(2);
  printf("자식 종료\n");
}
⚠️
wait(NULL);이 없으면 부모가 먼저 종료되어 좀비 프로세스가 발생할 수 있다.

예제 2: execl() 실행

printf("실행 전\n");
execl("/bin/ls", "ls", "-l", NULL);
printf("출력될까?\n");   // 실행 안 됨

execl이 실행되면 현재 프로세스가 ls로 대체되므로 이후 코드는 실행되지 않는다.

예제 3: fork() 중첩

fork();  // 2개 프로세스
fork();  // 4개 프로세스
fork();  // 8개 프로세스 (2³)

fork()는 자식 프로세스들을 생성하고 또 fork하면 그 자식들도 자식을 낳는다. 2ⁿ

예제 4: 변수 공유

int value = 5;
pid_t pid = fork();
if (pid == 0) { value += 15; return 0; }
else if (pid > 0) {
  wait(NULL);
  printf("PARENT: value = %d", value);  // 5
}
📌
fork() 시 새 프로세스는 원래 프로세스 주소 공간의 복사본으로 구성. 부모와 자식의 메모리는 독립적이므로 자식의 변경이 부모에 반영되지 않는다.
