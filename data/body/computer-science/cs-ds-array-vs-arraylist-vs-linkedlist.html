Array (배열)

크기
한번 정해지면 변경 불가
메모리
연속된 메모리 공간
조회
인덱스 O(1)
삽입·삭제
O(n) — 이후 요소 이동
장점
빠른 인덱스 접근 O(1), 메모리 사용 적음 (오버헤드 없음)
단점
크기 변경 불가, 삽입·삭제 비효율, 메모리 낭비 가능

ArrayList (동적 배열)

크기
동적 크기 조정. 부족하면 더 큰 배열 생성·복사
메모리
연속된 메모리 공간
조회
O(1)
삽입·삭제
O(n) — 느림
장점
크기 변경 가능, 빠른 조회 O(1), LinkedList보다 캐시 효율성 높음
단점
삽입·삭제 시 성능 저하 O(n), 크기 증가 시 복사 오버헤드

LinkedList (연결 리스트)

구조
노드(Node)와 포인터
메모리
비연속적 메모리 공간
조회
O(n) — 앞에서부터 탐색
삽입·삭제
O(1) — 중간에서도 가능
장점
삽입·삭제 빠름 O(1), 크기 제한 없음
단점
조회 느림 O(n), 포인터 저장 메모리 추가, 캐시 효율성 낮음
