선점 vs 비선점

선점 (Preemptive)
OS가 CPU 사용권을 강제 회수. 처리시간 예측 어려움
비선점 (Non-Preemptive)
프로세스 종료/I/O 이벤트까지 실행 보장. 처리시간 예측 용이

비선점 스케줄링 알고리즘

FCFS
First Come First Served — 큐에 도착한 순서대로 CPU 할당. 실행시간이 짧은 게 뒤로 가면 평균 대기시간 길어짐
SJF
Shortest Job First — 수행 시간이 가장 짧다고 판단되는 작업 먼저
HRN ⭐
Highest Response-ratio Next — 우선순위 = (대기시간+실행시간)/실행시간. SJF 보완

선점 스케줄링 알고리즘

Priority
우선순위 부여. starvation 발생 → Aging으로 해결
Round Robin
Time Quantum 만큼 CPU 할당. Quantum이 크면 FCFS, 작으면 오버헤드 증가
Multilevel Queue
우선순위/작업 유형별 여러 큐로 분류. 각 큐는 독립 스케줄링
Multilevel Feedback Queue
프로세스가 큐 간 이동. 짧게 실행되는 프로세스는 높은 우선순위 유지

스케줄링 척도

Response Time
작업이 처음 실행되기까지 걸린 시간
Turnaround Time
실행시간 + 대기시간. 작업 완료까지 총 시간
