파일 시스템
컴퓨터에서 파일이나 자료를 쉽게 발견할 수 있도록 유지·관리하는 방법

특징

  • 커널 영역에서 동작
  • 파일 CRUD 기능 수행
  • 계층적 디렉토리 구조
  • 디스크 파티션별로 하나씩 둘 수 있음

접근 방법

순차 접근
가장 간단. 포인터에서 시스템 콜 발생 시 포인터를 앞으로 보내며 read/write. 뒤로 돌아갈 땐 offset 만큼 되감기 (테이프 모델)
직접 접근
순서 없이 빠르게 레코드 read/write. 무작위 파일 블록에 임의 접근 허용 → DB에서 활용
색인 접근
직접 접근 파일에 기반한 색인 구축

디렉토리 구조

11단계 구조
가장 간단. 파일들은 서로 유일한 이름. 사용자가 다른 이름 사용 불가
22단계 구조
사용자별 개별 디렉토리 제공
3트리 구조
2단계 확장. 다단계 트리. 한 비트로 일반 파일(0)/디렉토리(1) 구분
4그래프 구조
하위 디렉토리가 아닌 파일에 대한 링크만 허용. 가비지 컬렉션으로 순환 방지
