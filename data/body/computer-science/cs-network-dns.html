DNS 서버 주소 찾기

DHCP (Dynamic Host Configuration Protocol)

호스트의 IP 주소와 TCP/IP 설정을 클라이언트에 자동 제공하는 응용 계층 프로토콜. 사용자는 DHCP 서버에서 자신의 IP, 라우터 IP, DNS 서버 IP를 받는다.

ARP (Address Resolution Protocol)

IP 주소 → 물리적 네트워크 주소(MAC) 변환. DHCP로 얻은 라우터 IP를 MAC 주소로 변환.

DNS 서버 계층 구조

1통신사 DNS 서버
DNS Query 전송
2루트 네임 서버
.com IP 반환
3.com 네임 서버
example.com IP 반환
4example.com 네임 서버
www.example.com IP 반환
🌍
최상위 계층(.com, .kr 등) 담당 DNS 서버는 전세계에 13개 뿐
