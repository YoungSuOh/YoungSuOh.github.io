⏳ Synchronous vs Asynchronous

Synchronous (동기)
작업이 순차적으로 실행. 한 작업 끝나야 다음 작업 시작
Asynchronous (비동기)
작업 실행 후 바로 다음 코드 실행. 응답이 오면 결과 처리. 여러 작업 동시 실행

🏛 Blocking vs Non-blocking

Blocking
작업 완료까지 현재 코드가 멈춤
Non-blocking
작업 완료 안 돼도 즉시 다음 코드로 넘어감

🎯 네트워크 프로그래밍 적용

방식설명예
Blocking I/Orecv() 호출 시 데이터 수신까지 멈춤socket.recv(1024)
Non-blocking I/Orecv() 호출해도 즉시 리턴socket.setblocking(False)
Synchronous I/O네트워크 요청을 순차 처리일반 HTTP 요청
Asynchronous I/O여러 요청을 동시 처리asyncio 기반 서버

🔥 4가지 조합

Blocking + Sync
직관적, but CPU가 놀게 됨. 소규모 앱
Blocking + Async
병렬이지만 각 요청은 Blocking. 성능 제한적
Non-blocking + Sync
여러 작업 처리 가능, but 응답 대기 길어질 수 있음. Node.js, Java NIO
Non-blocking + Async
가장 성능 뛰어남. 네트워크 서버, 대규모 시스템. Node.js, Python asyncio
