Race Condition
공유 자원에 대해 여러 프로세스가 동시에 접근할 때, 결과 값에 영향을 줄 수 있는 상태

발생하는 3가지 경우

1. 커널 작업 중 인터럽트

⚠️
프로세스가 커널 모드에서 공유 데이터 작업 중 하드웨어 인터럽트 발생 → 인터럽트 핸들러가 같은 데이터 조작 → 데이터 손상
해결: 인터럽트 비활성화
중요 작업 중에는 인터럽트를 비활성화하여 CPU 제어권 유지
해결: 원자적 연산
공유 데이터 작업을 원자적 연산으로 처리

2. System Call 중 Context Switch

프로세스1이 커널 모드에서 공유 데이터 조작 중 시간 초과로 Context Switch 발생 → 프로세스2가 같은 데이터 조작 → 데이터 불일치

해결: 시간 초과 방지
커널 모드 작업 중 CPU 제어권 넘기지 않도록 설정
해결: 락 기반 동기화
공유 데이터에 락 설정 → 한 번에 한 프로세스만 접근

3. 멀티 프로세서 환경의 공유 메모리

두 개 이상의 CPU가 동시에 공유 메모리 데이터를 수정 → 데이터 손상

Lock / Unlock
공유 데이터 사용 시 락 걸고 해제
Spinlock
멀티 프로세서에서 CPU가 락을 기다리며 실행 상태 유지
CAS
Compare-And-Swap 하드웨어 명령어로 원자적 처리
