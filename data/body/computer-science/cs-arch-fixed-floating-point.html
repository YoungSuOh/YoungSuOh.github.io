컴퓨터에서 실수를 표현하는 방법은 고정 소수점과 부동 소수점 두 가지가 존재한다.

1. 고정 소수점 (Fixed Point)

고정 소수점
소수점이 찍힐 위치를 미리 정해놓고 소수를 표현하는 방식 (정수부 + 소수부)

예제 (10비트, 소수부 6비트)

부호 (1)정수부 (3)소수부 (6)
0101110000
  • 101₂ = 5 (정수부)
  • 110000₂ = 0.75 (소수부, 1/2 + 1/4)
  • 최종: 5.75
장점
정수 연산처럼 간단, 연산 속도 빠름
단점
표현 범위 좁음, 소수점 위치 고정 → 유연성 부족

2. 부동 소수점 (Floating Point)

부동 소수점
소수점 위치가 가변적. 숫자를 가수(mantissa)와 지수(exponent)로 분리. IEEE 754 표준 사용

IEEE 754 단정밀도 (32비트)

부호 (1)지수 (8)가수 (23)
01000001010100000000000000000000
  • 부호: 0 → 양수
  • 지수: 10000010₂ = 130 → 실제 지수 = 130 - 127 = 3 (편향 지수)
  • 가수: 1.101₂ (가수는 항상 1을 포함)
  • 계산: 1.101₂ × 2³ = 1.625 × 8 = 13.0
장점
매우 큰/작은 수 표현 가능, 정밀 연산 가능
단점
연산 복잡·느림, 반올림 오차 발생 (0.1을 정확히 표현 불가)
