슬라이딩 윈도우는 연속 부분 배열/부분 문자열 문제를 O(N)에 해결할 때 자주 사용한다.

동작 원리

  • 오른쪽 포인터를 이동하며 윈도우 확장
  • 조건이 깨지면 왼쪽 포인터를 이동하며 축소
  • 각 단계에서 정답 후보를 갱신

Java 예제 (합이 target 이상인 최소 길이)

int left = 0, sum = 0, ans = Integer.MAX_VALUE;
for (int right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
        ans = Math.min(ans, right - left + 1);
        sum -= nums[left++];
    }
}

자주 나오는 문제

  • 최대/최소 길이 연속 구간
  • 문자 종류 제한(K개 이하)
  • 고정 길이 K 구간의 최대 합
