방향 그래프에서 간선으로 주어진 정점 간 선후 관계를 위배하지 않도록 나열하는 정렬

  • 위상 정렬을 했을 때 A는 C보다 앞에 등장해야 함
  • 하나의 그래프에는 여러 개의 위상 정렬 결과가 있을 수 있다.
    • ABCDEF, ACEDBF, BADCEF, BADFCE 등이 전부 올바른 위상 정렬
    • BDACED는 F가 D보다 먼저 나오기 때문에 잘못된 위상 정렬
  • 그래프 안에 사이클이 존재할 경우 올바른 위상 정렬이 존재할 수 없다.
  • 다음은 위상 정렬의 예이다 (대학교의 선수과목)

알고리즘의 설명

  • 제일 앞에 오는 원소는 들어오는 간선(indegree)이 0이어야 한다.
  • 임의로 A를 택하면 위상 정렬의 첫 정점은 A이다.
  • A와 A에서 뻗어나가는 간선을 제거한 것처럼 생각하고 다음 정점을 고른다.
  • 임의로 C를 택하고 같은 과정을 반복한다.

알고리즘 코드로 구현

  1. 정점/간선을 실제로 지우지 않고 indegree만 감소시켜도 된다.
  2. indegree 0 정점을 효율적으로 관리하기 위해 큐를 사용한다.
  1. 모든 간선을 읽으며 indegree 테이블 채우기
  2. indegree가 0인 정점들을 모두 큐에 넣기
  3. 큐에서 정점을 꺼내 결과에 추가
  4. 인접 정점 indegree를 1 감소, 0이 되면 큐에 추가
  5. 큐가 빌 때까지 반복
vector<int> adj[10];
int deg[10];
int n;

queue<int> q;
vector<int> result;

for (int i = 1; i <= n; i++) {
    if (deg[i] == 0) q.push(i);
}
while (!q.empty()) {
    int cur = q.front(); q.pop();
    result.push_back(cur);
    for (int nxt : adj[cur]) {
        deg[nxt]--;
        if (deg[nxt] == 0) q.push(nxt);
    }
}
if (result.size() != n)
    cout << "cycle exists";
else {
    for (auto x : result) cout << x << " ";
}

예제 코드 (Java)

import java.util.*;

public class TopologicalSortExample {
    public static List<Integer> topologicalSort(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[n + 1];

        for (int[] e : edges) {
            int u = e[0], v = e[1];
            graph.get(u).add(v);
            indegree[v]++;
        }

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            if (indegree[i] == 0) q.offer(i);
        }

        List<Integer> result = new ArrayList<>();
        while (!q.isEmpty()) {
            int cur = q.poll();
            result.add(cur);
            for (int nxt : graph.get(cur)) {
                if (--indegree[nxt] == 0) q.offer(nxt);
            }
        }

        if (result.size() != n) {
            throw new IllegalStateException("cycle exists");
        }
        return result;
    }

    public static void main(String[] args) {
        int n = 7;
        int[][] edges = {
                {1, 2}, {1, 3}, {2, 5},
                {3, 4}, {4, 6}, {5, 6}, {6, 7}
        };
        System.out.println(topologicalSort(n, edges));
    }
}
