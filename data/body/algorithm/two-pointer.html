Two Pointer는 하나의 배열(또는 문자열)에서 두 개의 포인터를 두고, 포인터를 이동시키며 원하는 조건을 찾는 알고리즘 기법이다.

핵심 아이디어

  • 완전 탐색의 중복 비교를 줄여 시간 복잡도를 개선한다.
  • 대부분 O(N) 또는 O(N log N)(정렬 포함)으로 해결 가능하다.
  • 포인터 이동 규칙(left++, right-- 등)을 명확히 정하는 것이 핵심이다.

대표 패턴 1: 양 끝에서 좁혀오기

정렬된 배열에서 합이 특정 값이 되는 두 수를 찾을 때 자주 사용한다.

  • sum < target 이면 왼쪽 포인터 증가
  • sum > target 이면 오른쪽 포인터 감소
  • sum == target 이면 정답 처리
public static boolean hasPairWithTarget(int[] arr, int target) {
    int left = 0;
    int right = arr.length - 1;

    while (left < right) {
        int sum = arr[left] + arr[right];
        if (sum == target) return true;
        if (sum < target) left++;
        else right--;
    }
    return false;
}

대표 패턴 2: 같은 방향으로 이동 (Sliding Window)

연속 부분 구간 조건(합, 길이, 포함 문자 등)을 다룰 때 사용한다.

  • 오른쪽 포인터로 윈도우 확장
  • 조건을 깨면 왼쪽 포인터로 윈도우 축소
  • 매 단계에서 정답 후보 갱신
public static int minSubArrayLen(int target, int[] nums) {
    int left = 0;
    int sum = 0;
    int answer = Integer.MAX_VALUE;

    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];

        while (sum >= target) {
            answer = Math.min(answer, right - left + 1);
            sum -= nums[left++];
        }
    }
    return answer == Integer.MAX_VALUE ? 0 : answer;
}

언제 쓰면 좋은가?

  • 정렬된 배열에서 두 수/세 수 조합 찾기
  • 팰린드롬 판별(양 끝 비교)
  • 연속 부분 배열의 최대/최소 길이 문제
  • 문자열에서 특정 조건을 만족하는 최소/최대 구간 문제
