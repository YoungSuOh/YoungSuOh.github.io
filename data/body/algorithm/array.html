배열(Array)

메모리 상에 원소를 연속하게 배치한 자료구조

배열의 성질

  • O(1) time 에 k번째 원소를 확인/변경 가능
  • 추가적으로 소모되는 메모리의 양(=overhead)가 거의 없음
  • Cache hit rate가 높음
  • 메모리 상에 연속한 구간을 잡아야 해서 할당에 제약이 걸림
  • 할당한 배열의 인덱스를 벗어나는 메모리 공간에 접근하면 Segment Fault가 발생한다.

배열의 시간 복잡도

  • 임의의 위치에 있는 원소를 확인/변경 = O(1) time
  • 원소를 끝에 추가 = O(1) time
  • 마지막 원소를 제거 = O(1) time
  • 임의의 위치에 원소를 추가/임의의 위치의 원소 제거 = O(N) time
