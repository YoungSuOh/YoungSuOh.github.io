BFS는 너비 우선 탐색으로, 시작점에서 거리가 가까운 노드부터 레벨 순서대로 방문한다.

핵심 특징

  • 큐(Queue) 자료구조를 사용한다.
  • 가중치가 없는 그래프에서 최단 거리(간선 수 기준)를 구할 때 유용하다.
  • DFS와 마찬가지로 방문 배열이 중요하다.

시간 복잡도

  • 인접 리스트 기준: O(V + E)
  • V: 정점 수, E: 간선 수

BFS 구현 (Java)

static void bfs(int start, List<List<Integer>> graph, boolean[] visited) {
    Queue<Integer> queue = new LinkedList<>();
    queue.offer(start);
    visited[start] = true;

    while (!queue.isEmpty()) {
        int cur = queue.poll();
        System.out.print(cur + " ");

        for (int next : graph.get(cur)) {
            if (!visited[next]) {
                visited[next] = true;
                queue.offer(next);
            }
        }
    }
}

언제 많이 쓰나?

  • 최소 이동 횟수(최단 거리) 문제
  • 격자 문제(미로, 섬 개수, 확산 시뮬레이션)
  • 레벨 단위 탐색(같은 깊이의 노드 처리)
